# Исходные расчёты

## 1. Размер и длина волны

Максимальный диаметр:

`D = 80 mm = 0.08 m`

### Ранние диапазоны проекта

Для свободного пространства:

`lambda = c / f`

Приближённо:

| f | lambda | D/lambda |
|---:|---:|---:|
| 2.0 ГГц | 150 мм | 0.53 |
| 3.0 ГГц | 100 мм | 0.80 |
| 8.5 ГГц | 35.3 мм | 2.27 |

Вывод: при ограничении 80 мм низкие диапазоны 2–3 ГГц дают электрически малую конструкцию. Для физического прототипа разумнее более высокая частота.

### Если стенд на HB100

`f = 10.525 GHz`

`lambda ≈ 28.5 mm`

`D/lambda ≈ 2.81`

Это предпочтительнее для компактной Ø80 мм линзы, чем 2–3 ГГц.

## 2. Идеальная линза Люнеберга

Радиус:

`R = 40 mm`

Идеальный профиль:

`epsilon_r(r) = 2 - (r/R)^2`

Граница:

- в центре: `epsilon_r(0) = 2`;
- на поверхности: `epsilon_r(R) = 1`.

## 3. Шесть зон

Радиус делится на шесть равных частей:

`dr = 40 / 6 = 6.667 mm`

Средние радиусы:

| zone | r_mid, мм | r/R | epsilon_r |
|---:|---:|---:|---:|
| 1 | 3.33 | 0.0833 | 1.993 |
| 2 | 10.00 | 0.2500 | 1.938 |
| 3 | 16.67 | 0.4167 | 1.826 |
| 4 | 23.33 | 0.5833 | 1.660 |
| 5 | 30.00 | 0.7500 | 1.438 |
| 6 | 36.67 | 0.9167 | 1.160 |

Формула таблицы:

`epsilon_zone = 2 - (r_mid/R)^2`

Это стартовая дискретизация. После измерения/оценки реального `epsilon_eff(infill)` значения должны быть заменены на достижимые.

## 4. Критерий ×10

Если требование относится к ЭПР/возвратной мощности:

`K = sigma_test / sigma_baseline = 10`

Тогда:

`Delta = 10*log10(10) = +10 dB`

## 5. Связь с дальностью обнаружения

Для классического радарного уравнения при остальных одинаковых условиях:

`R_max proportional sigma^(1/4)`

При `sigma2/sigma1 = 10`:

`R2/R1 = 10^(1/4) ≈ 1.78`

Это **ориентир**, а не прямой критерий для HB100: реальный модуль, алгоритм порога и среда могут изменить наблюдаемое отношение дальностей.

## 6. Фокус

Идеальная линза Люнеберга должна фокусировать плоскую падающую волну на противоположной поверхности линзы.

Для Ø80 мм исходное ожидание:

- центр линзы: `z = 0`;
- задняя поверхность: примерно `z = +40 mm`;
- фактический максимум необходимо определить в Meep.

Не фиксировать металл на `z=40 мм` только по теории. Сначала построить карту поля и найти реальный максимум для дискретной конструкции.

## 7. Отражающий сектор

После нахождения фокуса параметризовать полуугол металлического сектора:

`alpha = 10°, 20°, 30°, 45°`

Для каждого варианта сравнить on-axis backscatter.

Цель — выбрать минимальный сектор, после которого дальнейшее увеличение площади металла даёт малый выигрыш.

## 8. Угол

Минимальный sweep:

`theta = -20° ... +20°` шаг 5°.

На выходе получить:

- `backscatter(theta)`;
- `gain(theta)` относительно baseline;
- рабочий угловой сектор.
