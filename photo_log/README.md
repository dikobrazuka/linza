# Фотофиксация

Фото нужны не «для красоты», а как доказательство последовательности разработки.

## Обязательные кадры

1. исходный материал;
2. печать infill-образцов;
3. все тестовые образцы с подписями;
4. CAD линзы;
5. слайсер с зонами/заполнением;
6. процесс печати V1;
7. внутренняя структура полусферы/сегмента;
8. готовые части перед сборкой;
9. нанесение отражающего слоя;
10. готовый образец;
11. штангенциркуль с размером <=80 мм;
12. весы с массой <=300 г;
13. стенд целиком;
14. крупно радар/электроника;
15. каретка и крепление;
16. разметка трассы;
17. конфигурация BASELINE;
18. конфигурация LENS;
19. процесс приближения;
20. процесс удаления;
21. экран/лог данных;
22. угловой эксперимент;
23. итоговый образец рядом со стендом.

## Имена файлов

Не использовать `IMG_1234.jpg` как единственную идентификацию.

Пример:

```text
2026-10-30_01_material.jpg
2026-10-30_02_infill_samples.jpg
2026-11-02_03_lens_v1_print.jpg
2026-11-05_04_lens_v1_weight.jpg
2026-11-10_05_test_stand.jpg
```

## Для каждого важного фото

В `photo_log/index.md` позже фиксировать:

- дата;
- что изображено;
- версия образца;
- кто сделал;
- к какому этапу относится;
- ссылка на эксперимент/commit при необходимости.

## Главное правило

Фотографировать **до разборки/изменения стенда**, а не пытаться восстановить процесс перед защитой.
