# Фотофиксация

Фото — доказательство процесса, а не декоративный материал.

## Обязательные серии

1. DE-10 material/label/batch.
2. T1 plates + thickness measurement.
3. T2 coupons + dimensions/mass.
4. T3 gyroid coupons by rho.
5. Wash/post-cure process.
6. T4 RF coupons + measurement setup.
7. Technological gradient segment.
8. Current full physical candidate Ø120 mm before/after wash/cure.
9. Hemisphere alignment/seam.
10. Reflector manufacture.
11. Full 5-GHz stand.
12. BACKGROUND/HOLDER/REFERENCE/BASELINE/LENS_NO_REFLECTOR/LENS+REFLECTOR configurations.
13. Distance marks 1.0 / 1.25 / 1.5 m.
14. Angular stage.
15. Final mass/dimensions of physical 5-GHz lens.
16. Defense CAD/plots for strict-scaled Ø25 @24 GHz.

## Important

Do not photograph old Ø240 reference as if it were current physical V1. Current V1 candidate is Ø120 mm subject to diameter GO.

## Naming

Use:

`YYYY-MM-DD_stage_sample_description.ext`.

Example:

`2026-11-02_T3_GYR500_after_cure.jpg`.

## Index metadata

For important images record:

- date;
- sample/version;
- stage;
- git commit/config;
- operator;
- measurement/experiment link.
