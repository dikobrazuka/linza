# Журнал инженерных решений

Все значимые изменения проекта фиксировать здесь. Не менять ключевые параметры «по памяти» без записи причины.

## D-001 — ограничение габарита и массы

**Решение:** образец <=80 мм, масса <=300 г.

**Источник:** промежуточная встреча с экспертом.

---

## D-002 — основной инструмент моделирования

**Решение:** использовать **Meep** как основной электродинамический инструмент.

---

## D-003 — сценарий натурного движения

**Решение:** если проводится динамическая демонстрация, цель движется по оси радара — приближение и удаление. Боковой пролёт не использовать как основной сценарий.

---

## D-004 — критерий ×10

**Рабочее толкование:** увеличение обратного рассеяния/ЭПР в 10 раз относительно baseline, то есть +10 dB по мощности/ЭПР.

**Статус:** baseline должен быть явно указан в отчёте. Для стендового сравнения текущий рабочий baseline — металлическая контрольная мишень Ø80 мм; при необходимости эксперт может уточнить другой baseline.

---

## D-005 — основной физический стенд

**Дата:** 2026-10-27

**Решение:** основной количественный эксперимент выполнять на **стационарном двухантенном VNA-стенде** на 24 ГГц.

Схема:

`VNA Port 1 -> TX horn -> TARGET -> RX horn -> VNA Port 2`

**Причина:** обработанные показатели дешёвых presence-radar модулей и простой Doppler-IF не позволяют так чисто доказать статическое изменение ЭПР ×10. VNA даёт комплексный S21, позволяет фоновое вычитание и time gating.

**Следствие:** старые варианты HB100/RCWL/CDM324/Arduino/servo не являются основным стендом.

---

## D-006 — измерительные конфигурации

**Решение:** снимать минимум:

1. BACKGROUND;
2. HOLDER;
3. METAL Ø80;
4. LENS;
5. LENS+METAL.

Менять только мишень. Геометрию, VNA, антенны, кабели и настройки сохранять неизменными.

---

## D-007 — обработка относительной ЭПР

**Решение:** вычитать фон комплексно:

`H = S21_target - S21_background`.

Считать:

`K_sigma = |H_lens|^2 / |H_base|^2`.

Эквивалент в dB:

`Delta_sigma_dB = 20*log10(|H_lens|/|H_base|)`.

`+10 dB -> K_sigma = 10`.

Абсолютную ЭПР в м² без отдельной RCS-калибровки не заявлять.

---

## D-008 — геометрия VNA-стенда

**Решение:** стартовая дистанция TX/RX -> мишень **2.0 м**. TX и RX на общей базе, центры разнесены ориентировочно на 100–150 мм. Мишень — на диэлектрической стойке и поворотной платформе.

---

## D-009 — угловой эксперимент

**Решение:** снимать минимум `-30...+30°` шаг 5°.

**Причина:** плоская металлическая пластина на 0° может иметь очень сильный зеркальный возврат; преимущество Luneburg-ретрорефлектора нужно оценивать по всей угловой характеристике.

---

## D-010 — частоты

**Решение:** физический VNA-эксперимент ориентировать на **24.125 ГГц**. В Meep оставить минимум 3 разнесённые частоты и обязательно включить 24.125 ГГц для прямого сравнения с экспериментом.

Широкий VNA sweep, например 18–26.5 ГГц при наличии соответствующих рупоров, используется в первую очередь для time-domain gating.

---

## D-011 — геометрия линзы

**Решение:** не фиксировать полный шар автоматически. Сравнить в Meep:

1. полный шар + металлический сектор;
2. полусфера + металлическая плоскость/отражатель.

После сравнения выбрать геометрию по backscatter, углу, массе и технологичности.

---

## D-012 — структура линзы

**Решение:** стартовая технологичная архитектура — 6 радиальных зон.

Идеальный профиль:

`epsilon_r(r)=2-(r/R)^2`.

Важно: εr зоны не равна проценту infill. Нужна отдельная зависимость `infill -> epsilon_eff` либо обоснованная оценка.
