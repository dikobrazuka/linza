# LINZA — аддитивная линза Люнеберга для БПЛА

Рабочий репозиторий команды «Градиент».

## Цель проекта

Разработать, изготовить и экспериментально проверить компактный пассивный радиолокационный отражатель на основе 3D-печатной линзы Люнеберга для БПЛА.

### Зафиксированные ограничения после промежуточной встречи с экспертом

- максимальный габарит образца: **80 мм**;
- максимальная масса: **300 г**;
- изготовление: **FDM**;
- моделирование: **Meep**;
- ключевые расчётные параметры: фокус, фокальное пятно, обратное рассеяние/ЭПР, угловая характеристика;
- рабочая цель: прирост обратного рассеяния **не менее 10 раз** относительно базовой конфигурации;
- эксперимент: движение цели **по оси радара — приближение и удаление**, без бокового пролёта;
- обязательная фотофиксация всех промежуточных этапов.

## Основной цикл разработки

**модель → фокус → зональная структура → отражатель → CAD/FDM → стенд → эксперимент → сравнение → корректировка**

## Текущее главное направление

Первый физический прототип проектируется как компактная многозонная FDM-линза с отражающим металлическим сектором. Конкретная частота физического стенда выбирается совместно с доступным оборудованием; расчёт в Meep должен выполняться на фактической частоте эксперимента.
