# LINZA — аддитивная линза Люнеберга для БПЛА

Рабочий репозиторий команды «Градиент».

## Цель проекта

Разработать, изготовить и экспериментально проверить компактный пассивный радиолокационный отражатель на основе 3D-печатной линзы Люнеберга для БПЛА.

## Зафиксированные ограничения

- максимальный габарит образца: **80 мм**;
- максимальная масса: **300 г**;
- изготовление: **FDM**;
- моделирование: **Meep**;
- ключевые расчётные параметры: фокус, фокальное пятно, обратное рассеяние/ЭПР, угловая характеристика;
- рабочая цель: прирост обратного рассеяния **не менее 10 раз**, что соответствует **+10 dB по ЭПР/мощности** относительно выбранной baseline-конфигурации;
- обязательная фотофиксация всех промежуточных этапов.

## Текущая экспериментальная стратегия

### Основной количественный эксперимент

Использовать **стационарный двухантенный VNA-стенд на 24 ГГц**:

`VNA Port 1 -> TX horn -> TARGET -> RX horn -> VNA Port 2`

Измерять комплексный `S21(f)` для:

1. `BACKGROUND` — пустой стенд;
2. `HOLDER` — держатель без мишени;
3. `METAL` — контрольная металлическая мишень Ø80 мм;
4. `LENS` — диэлектрическая линза без отражателя;
5. `LENS+METAL` — конечный ретрорефлектор.

Основная физическая частота: **24.125 ГГц**. Широкий sweep, например 18–26.5 ГГц при наличии соответствующих рупоров, используется для time-domain/time-gating и отделения мишени от отражений помещения.

Критерий:

`K_sigma = |H_lens|^2 / |H_base|^2`

где после комплексного фонового вычитания:

`H = S21_target - S21_background`.

Цель: `K_sigma >= 10`, эквивалентно `Delta RCS >= +10 dB`.

### Угловой эксперимент

Снять `K_sigma(theta)` минимум в диапазоне **-30...+30°** с шагом 5°. Главное преимущество линзы ожидается не только на 0°, а в сохранении сильного возврата при отклонении от нормали.

### Динамический опыт

Движение БПЛА к радару и от радара оставить как **натурную демонстрацию применения** и как выполнение экспертного сценария, но не использовать как основной способ количественно доказывать ×10 ЭПР.

## Моделирование

В Meep проверить одну и ту же физическую конструкцию минимум на трёх разнесённых частотах, например:

- ~3 ГГц;
- ~10.5 ГГц;
- **24.125 ГГц**.

Для 24.125 ГГц обязательно сопоставить модель с физическим экспериментом.

Стартовый профиль:

`epsilon_r(r) = 2 - (r/R)^2`, `R = 40 мм`.

Технологическая аппроксимация: 6 радиальных зон. Связь `infill -> epsilon_eff` не считать равной проценту заполнения; её нужно измерить или обоснованно оценить.

## Геометрия линзы

Текущий кандидат для облегчённого прототипа — **полусфера Ø80 мм с металлической плоскостью/отражателем**, но перед фиксацией CAD сравнить в Meep:

1. полный шар + металлический сектор;
2. полусфера + металлическая плоскость.
