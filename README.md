# LINZA — аддитивная линза Люнеберга для БПЛА

Рабочий репозиторий команды «Градиент».

## Цель проекта

Разработать, изготовить и экспериментально проверить компактный пассивный радиолокационный отражатель на основе 3D-печатной линзы Люнеберга для БПЛА.

## Ограничения конечной конструкции

- максимальный габарит образца: **80 мм**;
- максимальная масса: **300 г**;
- рабочий диапазон проекта: **8–24 ГГц**;
- изготовление: **FDM**;
- моделирование: **Meep**;
- рабочая цель: прирост обратного рассеяния/ЭПР **не менее 10 раз**, то есть **+10 dB**, относительно явно выбранной baseline-конфигурации.

## Текущая экспериментальная стратегия

Доступный NanoVNA-F V3 работает только до 6 ГГц, поэтому прямое измерение конечной Ø80-мм конструкции на 8–24 ГГц им невозможно.

Текущий физический прототип фиксируется как масштабная модель:

### TEST_LENS_5G_V1

- физическая частота: **5.0 ГГц**;
- диаметр: **240 мм**;
- радиус: **120 мм**;
- масштаб относительно конечной конструкции: **3:1**;
- электромагнитно подобный конечный вариант: **Ø80 мм @ 15 ГГц**;
- 15 ГГц находится внутри заданного диапазона 8–24 ГГц;
- стартовый серьёзный вариант: **11 радиальных зон**;
- characteristic lattice/cell для первого CAD: ориентир **~10 мм**;
- сравниваем две архитектуры: `full sphere + metal cap` и `hemisphere + metal ground plane`.

Масштабирование основано на сохранении нормированных геометрических параметров `D/lambda`, размеров зон, lattice и отражателя. Абсолютная ЭПР в м² при масштабировании не сохраняется; сохраняются нормированные характеристики и, при выполнении условий подобия, относительный RCS-gain.

## Meep

До печати выполнить сравнение на 5 ГГц:

1. homogeneous sphere — контроль;
2. ideal continuous Luneburg;
3. 6-zone;
4. 8-zone;
5. 11-zone;
6. выбранная printable lattice geometry;
7. full sphere + cap;
8. hemisphere + ground plane.

Для финалистов снять `RCS(theta)` и `K_sigma(theta)`.

После выбора физической архитектуры проверить масштабированную Ø80-мм конструкцию минимум на **15 ГГц**, а также отдельно на **24 ГГц** как верхнюю расчётную точку диапазона.

## Физический эксперимент

Основной тракт:

`NanoVNA Port 1 -> TX antenna -> TARGET -> RX antenna -> NanoVNA Port 2`

Сохранять комплексный `S21(f)`, выполнять background subtraction и при достаточной полосе — time-domain gating.

Для масштабной модели Ø240 мм на 5 ГГц стартовую дистанцию брать **не менее ~2 м**, практично **2.5–3 м**, чтобы выйти в дальнюю зону.

Металлическая сфера/пластина используется как **калибровочная/reference target**, а не как главный baseline для требования ×10. Проектный baseline должен быть определён отдельно и явно указан в отчёте.

## Профиль линзы

Идеальный профиль:

`epsilon_r(r) = 2 - (r/R)^2`.

Для TEST_LENS_5G_V1: `R = 120 мм`.

Связь `infill -> epsilon_eff` не считать равной проценту заполнения; нужна измеренная или обоснованно рассчитанная зависимость.
