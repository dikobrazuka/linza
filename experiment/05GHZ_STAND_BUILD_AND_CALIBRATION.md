# СТЕНД 5 ГГц — сборка, антенны, калибровка, контроль

Ревизия STAND-5G-R1 / 09.11.2026. **Не выполнено, проект инструкции.** Применяется к двум независимым образцам: **PLA/FDM Ø200 мм** и **HARZ DE-10 / MSLA Ø120 мм**. Для заказного Ø80 @24 ГГц этот стенд не является прямой проверкой на 24 ГГц.

## 1. Блок-схема RF соединения

```text
           кабель SMA-M/SMA-M 1 м                       кабель SMA-M/SMA-M 1 м
NanoVNA-F V3 Port 1 ────────── [TX double-ridged horn]   [RX double-ridged horn] ────────── Port 2
                                              \          /
                                               \        /
                                           TARGET Ø200 PLA ИЛИ Ø120 DE-10
                                         на диэлектрической стойке
                              TX/RX смотрят на центр одного объекта
```

Это bistatic co-polarized S21 measurement с конечным расстоянием между рупорами. Не называть его автоматически строгим monostatic RCS: нужно отдельно обосновать бистатический угол, расстояния и приближённый пересчёт.

## 3. Изготовление двух рупоров (вместо «просто намазать фольгой»)

1. Скачать/открыть **конкретный STEP рупора ByTechLab**. Зафиксировать ревизию и размеры апертуры/щели/двух гребней, чтобы потом можно было воспроизвести два одинаковых изделия.
2. Измерить реальный SMA-7814-16 штангенциркулем: положение винтов, длину свободного центрального штыря, длину PTFE, толщину фланца. Подогнать посадку CAD **до печати**, а не располагать контакт «примерно».
3. Напечатать два корпуса, две задние пластины, держатели. Очистить грани; не допускать пластика, выступающего в щель возбуждения между гребнями.
4. Обезжирить при допустимости для материала, высушить. Медную ленту наклеивать на внутренние поверхности от узкой щели к апертуре; исключать морщины, зазоры, выступающие складки в щели.
5. Изолированные перехлёсты соединять намеренно: проводящий клей только в нужных местах, либо механический прижим/пайка там, где это безопасно для пластика. **DC прозвонка не гарантирует непрерывность RF тока на 5 ГГц**.
6. Фланец/наружный экран SMA должен иметь непрерывный контакт с предусмотренной конструкцией стенкой/гребнем; центральный контакт соединяется с **предусмотренным противоположным гребнем** без замыкания на экран.
7. До подключения VNA прозвонить: signal SMA center ↔ RF-ground/flange **не короткое замыкание** в проверяемой геометрии; целевой центр ↔ гребень имеет контакт; экран ↔ предназначенная наружная металлизация имеет контакт. Если конкретная модель конструкции подразумевает иной DC контакт, ориентироваться по её проверенному чертежу, не по универсальному совету.
8. Прикрепить заднюю пластину; все стенки держать ровными, одинаковыми у двух экземпляров. Сфотографировать швы, разъём, внутренности до закрытия и общий вид.
9. Закрепить два рупора на стойках так, чтобы их оси на одной высоте, одинаковая поляризация, кабели не тянут разъёмы. Вблизи апертуры не ставить металлические уголки и стойки, которые отражают сами по себе.

## 4. Калибровка прибора: не перепутать МГц с ГГц

10. Проверить S11 портов и кабелей на безопасной тестовой нагрузке. Осмотреть SMA, не перетягивать тонкие разъёмы.
11. Установить центр **5.0 ГГц**, например span 1 ГГц (4.5–5.5 ГГц), число точек по возможности ≥201, фиксированный диапазон, усреднение при слабом сигнале. Подтвердить реальную работоспособность NanoVNA-F V3 на выбранном диапазоне.
12. Прибор ранее калибровался на **383–483 МГц**. Эту калибровку **не применять**. Калибровать заново OPEN/SHORT/LOAD для нужных портов и THRU согласно меню конкретной прошивки, на концах **подключённых измерительных кабелей**, задать единые reference planes, SAVE в отдельный слот, записать дату/частотный интервал.
13. Подключить сначала отдельно первый и второй рупоры; снять **S11 каждого** (логарифмический модуль и по возможности комплексную часть). Если провал отсутствует/возникает странное КЗ/прыгает при касании, остановить опыт, исправить разъём/металлизацию/кабель.
14. Направить TX прямо на RX на известной небольшой дистанции (не в упор) и проверить **S21 тракта**, при этом подобрать безопасную геометрию, не насыщать приёмный тракт. Сохранить baseline антенного канала.
15. Поставить рупоры рядом, направить на точку мишени, измерить **BACKGROUND** без мишени, затем HOLDER (одна пустая стойка), REFERENCE (металлическая мишень). Пробовать разные TX/RX separation так, чтобы прямая связь и комнатные многолучевые отражения не забивали отражение от образца.

## 5. Геометрия для разных линз

| Образец | Диаметр | Объектная дальняя зона по 2D²/λ | Первые проверочные R от линзы до рупоров |
|---|---:|---:|---|
| PLA-200-5G | 200 мм | ≈1.334 м | **2.0 / 2.5 / 3.0 м** |
| DE10-120-5G | 120 мм | ≈0.480 м | **1.0 / 1.25 / 1.5 м** |

Эти R — не норматив точного RCS. Требования дальней зоны рупоров, TX/RX separation, динамического диапазона и background могут потребовать **больших** дистанций. Выбрать первую геометрию только если REFERENCE и BASELINE воспроизводимо отделены от background/noise.

## 6. Правила замеров

Перед каждой серией записать частотный диапазон, точки, усреднение, выбранный калибровочный слот, расстояния TX→center и RX→center, высоту, горизонтальное смещение рупоров, угол между лучами, поляризацию, материал стойки, положение кабелей, температуру/влажность по возможности.

Для **каждой** линзы отдельно:
1. BACKGROUND / HOLDER / REFERENCE, затем BASELINE (отражатель **без** диэлектрика, на аналогичном держателе).
2. Диэлектрик без отражателя (если конструкция позволяет), затем линза с **тем же** отражателем в одинаковом положении.
3. Для baseline и lens+reflector не меньше **3 независимых установок**, не просто 3 sweep без перестановки.
4. При нестабильности сначала устранить фон/кабели, только затем считать dB.
5. Сохранять **комплексное S21** в Touchstone .s2p или эквивалентном формате. **Запись только LogMag не позволяет сделать комплексное background subtraction**.
6. Измерить несколько расстояний и минимум 0°, затем углы -30°…+30° с шагом 5° при подтверждённой центральной точке.

### Обработка

H_state(f)=S21_state(f)−S21_BACKGROUND(f) на одной частотной сетке.

Если baseline хорошо выше шума и stand validation пройден: Δ = 20log10(|H_lens+reflector|/|H_baseline|); Kσ_proxy=10^(Δ/10). Это относительная оценка **при определённых RF геометрии и калибровке**, а не автоматическое абсолютное dBsm. Изменение S21 в комнате может включать interference и multipath. Для абсолютного RCS необходим эталон известного scattering и корректная модель всей геометрии.

**GO перед измерением линзы:** оба рупора проверены, работающий 5-ГГц слот калибровки, reference стабильно выше фона, кабели зафиксированы, стенд не меняется между парами измерений. Если не GO — данные не использовать для claim «+10 дБ».
