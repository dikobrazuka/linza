# Экспериментальный стенд и методика

## Цель

Сравнить возвратный радиолокационный сигнал от одной и той же базовой конфигурации:

- без линзы;
- с линзой;

при движении строго по оси источника/радара.

## Принцип

Эксперт зафиксировал основной сценарий:

- приближение к радару;
- удаление от радара;
- без бокового пролёта.

Для студенческого стенда допускается не абсолютное измерение ЭПР, а **повторяемое относительное сравнение уровня возвратного сигнала и дальности обнаружения**.

## Базовая дешёвая архитектура

Предпочтительный демонстрационный вариант при отсутствии лабораторного VNA:

- готовый X-band Doppler radar module (например, HB100/аналог);
- усилитель низкочастотного IF-сигнала;
- АЦП/осциллограф/микроконтроллер;
- ноутбук для логирования;
- неметаллическая каретка цели;
- трасса движения по оси радара.

Важно: физическая модель в Meep должна рассчитываться **на фактической частоте выбранного радара**, а не на условной частоте из раннего обзора.

## Почему moving-target radar подходит

Doppler-модуль сам содержит:

- СВЧ-источник;
- антенну передачи;
- приёмную антенну;
- смеситель.

На выходе формируется IF/Doppler-сигнал при движении цели. Это соответствует требованию эксперта о приближении/удалении и позволяет сравнить амплитуду и дальность обнаружения с линзой и без неё.

## Механика стенда

### Радар

- жёстко закрепить;
- не двигать между сериями;
- высота центра радара = высота центра линзы;
- направить строго вдоль трассы.

### Трасса

- прямая линия по оси радара;
- ориентировочная длина определяется реальной дальностью модуля;
- разметка расстояния через 0.25–0.5 м;
- убрать крупные металлические объекты около трассы насколько возможно.

### Каретка

Не держать образец руками.

Использовать:

- PLA/PETG/дерево/пеноматериал;
- минимум металла;
- фиксированную стойку;
- одинаковую ориентацию при всех проходах;
- движение шнуром или простым дистанционным приводом, чтобы оператор не находился рядом с целью.

## Конфигурации

Минимум:

1. `EMPTY` — пустая трасса;
2. `BASELINE` — каретка + держатель без линзы;
3. `LENS` — та же каретка + линза;

Полезно дополнительно:

4. `REFLECTOR_ONLY` — металлический отражатель без линзы;
5. `LENS_NO_REFLECTOR` — линза без металла.

Это позволяет доказать, что прирост связан именно с системой «линза + отражатель», а не только с металлом.

## Электрическая часть

### Вариант с HB100/аналогом

`Radar IF output -> low-noise/active amplifier -> ADC/oscilloscope -> laptop`

На IF-сигнале измерять:

- RMS/peak amplitude;
- спектральный пик Doppler;
- SNR относительно фонового уровня.

Для защиты проще всего использовать один заранее зафиксированный показатель, например RMS амплитуду в рабочем Doppler-диапазоне.

## Калибровка перед опытом

1. Прогреть электронику 5–10 минут.
2. Записать 30–60 секунд пустой трассы.
3. Определить средний фон и шум.
4. Зафиксировать порог обнаружения, например:
   - `threshold = mean_noise + 6 dB`, либо
   - другой заранее выбранный и одинаковый для всех серий критерий.
5. После выбора порога **не менять его между baseline и lens**.

## Один проход

### Приближение

1. Поставить каретку в дальней точке.
2. Начать движение к радару с приблизительно постоянной скоростью.
3. Записывать сигнал непрерывно.
4. Записать расстояние первого устойчивого превышения порога.
5. Продолжить до ближней точки.

### Удаление

1. Не менять ориентацию цели.
2. Двигать каретку от радара.
3. Записывать сигнал непрерывно.
4. Зафиксировать расстояние потери устойчивого обнаружения.

## Повторения

Минимум на каждую конфигурацию:

- 5 приближений;
- 5 удалений.

Лучше чередовать серии:

`BASELINE -> LENS -> BASELINE -> LENS ...`

Это снижает влияние дрейфа условий.

## Что записывать

Каждая запись должна содержать:

- timestamp;
- configuration;
- run_number;
- direction (`APPROACH` / `RECEDE`);
- distance_m либо синхронизированную метку расстояния;
- raw_signal;
- filtered_signal;
- detection_threshold;
- detected yes/no;
- notes.

## Угловой эксперимент

Основной опыт остаётся по оси.

После него:

1. зафиксировать цель на одной дистанции;
2. повернуть сборку относительно радара;
3. измерить минимум:
   - -20°;
   - -15°;
   - -10°;
   - -5°;
   - 0°;
   - +5°;
   - +10°;
   - +15°;
   - +20°;
4. сравнить с расчётной угловой характеристикой Meep.

## Отдельная проверка фокуса

Если есть возможность сделать локальный RF-probe/приёмник, до нанесения металла полезно физически проверить область максимального поля за линзой и сравнить её с Meep.

Если подходящего СВЧ-пробника нет, этот эксперимент не является обязательным для базовой защиты: положение фокуса подтверждается численно, а итоговая эффективность — измерением возвратного сигнала.

## Итоговые показатели

Для каждой конфигурации получить:

- среднюю/медианную дальность первого обнаружения;
- среднюю/медианную дальность потери;
- амплитуду/RMS сигнала на одинаковых участках движения;
- стандартное отклонение;
- относительный прирост Lens/Baseline.

## Правило честного сравнения

Между baseline и lens запрещено менять:

- мощность/питание радара;
- положение радара;
- высоту цели;
- траекторию;
- ориентацию держателя;
- скорость движения намеренно;
- алгоритм обработки;
- порог обнаружения.
