# Экспериментальный стенд и методика

## Цель

Проверить **одну и ту же линзу на трёх рабочих частотах проекта**:

- **2 ГГц**;
- **3 ГГц**;
- **8.5 ГГц**.

Для каждой частоты отдельно сравнить радиолокационный отклик:

- без линзы;
- с линзой.

Основной сценарий, согласованный с экспертом:

- приближение к радару;
- удаление от радара;
- движение строго по оси;
- без бокового пролёта.

## Почему именно эти три частоты

Эти частоты уже зафиксированы в презентации и являются рабочими диапазонами проекта. Эксперимент должен подтверждать работу линзы именно на них, а не на удобных частотах дешёвых готовых модулей.

Для диаметра 80 мм:

| Частота | λ в воздухе | D/λ |
|---:|---:|---:|
| 2 ГГц | ≈150 мм | ≈0.53 |
| 3 ГГц | ≈100 мм | ≈0.80 |
| 8.5 ГГц | ≈35.3 мм | ≈2.27 |

Это означает, что один и тот же образец находится в принципиально разных электрических размерах. Именно поэтому многодиапазонная проверка является важной частью исследования.

## Ключевой принцип сравнения

Нельзя напрямую сравнивать абсолютный уровень сигнала разных трактов на 2, 3 и 8.5 ГГц: у них будут различаться мощности, антенны, усиление и чувствительность.

На каждой частоте отдельно считается относительный эффект линзы:

`G(f) = отклик с линзой / отклик без линзы`

Итоговая таблица:

| Частота | Без линзы | С линзой | Относительный прирост |
|---:|---:|---:|---:|
| 2 ГГц | ... | ... | ... дБ |
| 3 ГГц | ... | ... | ... дБ |
| 8.5 ГГц | ... | ... | ... дБ |

## Архитектура эксперимента

Механика стенда остаётся общей для всех трёх частот:

`источник/радар -> цель на каретке -> приёмный тракт -> регистрация данных`

Меняется только радиочастотный тракт.

Одна и та же:

- трасса;
- каретка;
- БПЛА или его макет;
- линза;
- ориентация;
- скорость движения;
- алгоритм обработки.

## Механика

### Радиочастотный блок

Закрепляется жёстко в начале трассы. При смене диапазона ось антенны должна оставаться той же.

### Трасса

- прямая линия;
- цель движется строго на источник/радар и от него;
- ориентировочная длина 1–5 м для первого стенда;
- разметка через 0.25–0.5 м;
- по возможности убрать крупные металлические объекты рядом.

### Цель

Использовать один и тот же БПЛА или макет на одной каретке.

Основные конфигурации:

1. `DRONE_BASE` — без линзы;
2. `DRONE_LENS` — тот же объект с линзой.

Полезно для диагностики:

3. `LENS_ONLY`;
4. `REFLECTOR_ONLY`;
5. `LENS_NO_REFLECTOR`.

## Серия на каждой частоте

Для 2, 3 и 8.5 ГГц выполнять одинаковый протокол:

1. прогреть электронику;
2. записать фон;
3. 5 приближений `DRONE_BASE`;
4. 5 приближений `DRONE_LENS`;
5. 5 удалений `DRONE_BASE`;
6. 5 удалений `DRONE_LENS`;
7. рассчитать относительный прирост;
8. сохранить сырые данные и условия опыта.

После этого переходить на следующую частоту.

## Скорость движения

Скорость должна быть максимально одинаковой между сериями. Лучше использовать простой привод/лебёдку. Если движение ручное — скорость измерять по видео и разметке.

## Что измерять

На каждой частоте:

- амплитуду принимаемого/IF-сигнала;
- SNR относительно фона;
- дальность первого устойчивого обнаружения;
- дальность потери обнаружения;
- относительный прирост `LENS / BASELINE`.

## Угловой эксперимент

После осевых прогонов на каждой частоте зафиксировать цель на одной дистанции и снять минимум:

- -20°;
- -15°;
- -10°;
- -5°;
- 0°;
- +5°;
- +10°;
- +15°;
- +20°.

Это даст зависимость эффективности от ошибки ориентации.

## Связь с Meep

Одну и ту же физическую геометрию моделировать минимум на:

- 2 ГГц;
- 3 ГГц;
- 8.5 ГГц.

Не оптимизировать три разные линзы, если задача — доказать работу **одного образца в трёх диапазонах**.

Для каждой частоты получить:

- карту поля;
- положение фокуса;
- размер фокального пятна;
- обратное рассеяние;
- угловую характеристику.

## Итог защиты

Главный график:

`относительный прирост радиолокационного отклика, дБ` vs `частота: 2 / 3 / 8.5 ГГц`.

Дополнительно:

- дальность обнаружения по каждой частоте;
- угловая характеристика;
- сравнение Meep и эксперимента.

## Важно

HB100 10.525 ГГц может использоваться только как дешёвый отладочный модуль для проверки механики, усилителя и логирования. Он **не заменяет** обязательную экспериментальную точку 8.5 ГГц и не входит в финальный набор трёх рабочих частот проекта.
