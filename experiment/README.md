# Экспериментальный стенд и методика

## Цель

Количественно сравнить обратное рассеяние контрольной металлической мишени и 3D-печатной линзы Люнеберга с отражателем на **24.125 ГГц**, а затем снять угловую характеристику.

Основной физический эксперимент теперь **стационарный**. Движущийся Mavic — отдельная натурная демонстрация применения, а не основной RCS-измеритель.

## Основная схема

`VNA Port 1 -> TX horn -> TARGET -> RX horn -> VNA Port 2`

Используется двухрупорная S21-схема.

### Требования к VNA

- 2 порта;
- верхняя частота не ниже 24.25 ГГц, предпочтительно 26.5 ГГц и выше;
- комплексный S21: амплитуда + фаза;
- частотный sweep;
- экспорт Touchstone/CSV;
- желательно Time Domain / Time Gating;
- регулируемый IFBW и averaging.

### Требования к антеннам

Предпочтительно 2 одинаковых рупора диапазона **18–26.5 ГГц** (WR-42), усиление ориентировочно 15–20 dBi.

## Геометрия стенда

- расстояние от пары рупоров до центра мишени: стартово **2.0 м**;
- центры TX/RX: ориентировочно **100–150 мм** друг от друга;
- TX и RX закреплены на общей жёсткой планке;
- оси обоих рупоров направлены в центр мишени;
- центр мишени на одной высоте с центрами антенн;
- мишень желательно держать минимум ~1 м от крупной задней стены/металла;
- стойка мишени — преимущественно диэлектрическая.

Для D=80 мм и 24.125 ГГц граница дальней зоны по оценке `2D^2/lambda` около 1 м, поэтому 2 м даёт практический запас.

## Конфигурации измерения

Последовательно снять:

1. `BACKGROUND` — без мишени;
2. `HOLDER` — только держатель;
3. `METAL` — металлический диск Ø80 мм;
4. `LENS` — линза без металлического отражателя;
5. `LENS_METAL` — конечная линза с рассчитанным отражателем.

Меняется только мишень. Антенны, кабели, VNA, мощность, IFBW и геометрия остаются неизменными.

## Стартовые настройки VNA

Если доступны рупоры 18–26.5 ГГц:

- sweep: **18–26.5 ГГц**;
- points: **3201**, при возможности 6401;
- source power: стартово **0 dBm**;
- IFBW: стартово **1 kHz**, при шуме снизить до 100 Hz;
- averaging: **8–16**;
- сохранять комплексный S21.

Широкий sweep нужен прежде всего для time-domain gating. Сам итоговый коэффициент сравнения фиксируется около **24.125 ГГц**.

## Калибровка

Перед измерениями выполнить 2-port calibration на концах двух СВЧ-кабелей. После калибровки подключить рупоры и не перемещать кабели без необходимости.

Если встроенного Time Domain нет, экспортировать комплексный S21 и сделать IFFT/time gate в Python.

## Обработка

Комплексное фоновое вычитание:

`H_M(f) = S21_METAL(f) - S21_BACKGROUND(f)`

`H_L(f) = S21_LENS_METAL(f) - S21_BACKGROUND(f)`

Не вычитать значения уже в dB.

Относительный коэффициент:

`K_sigma = |H_L|^2 / |H_M|^2`

В dB:

`Delta_sigma_dB = 20*log10(|H_L|/|H_M|)`

При:

`Delta_sigma_dB = +10 dB`

получаем:

`K_sigma = 10`.

Корректная формулировка: **относительное обратное рассеяние / относительная ЭПР конечной конфигурации выросла в 10 раз относительно выбранной baseline-конфигурации при данной частоте, поляризации и угле**.

Абсолютную ЭПР в м² не заявлять без отдельной RCS-калибровки по эталонной мишени.

## Угловой эксперимент

Мишень устанавливается на поворотную платформу, ось вращения проходит через центр линзы.

Минимальный sweep:

`theta = -30° ... +30°`, шаг **5°**.

Для каждого угла снять минимум `METAL` и `LENS_METAL`.

Построить:

`K_sigma(theta) = sigma_LENS_METAL(theta) / sigma_METAL(theta)`.

Важно: плоская металлическая пластина на 0° сама может иметь сильный зеркальный возврат. Поэтому ключевой эффект линзы нужно оценивать по всей угловой характеристике, а не только по точке 0°.

## Связь с Meep

В Meep:

1. идеальная непрерывная линза;
2. 6-зонная аппроксимация;
3. выбранная реальная геометрия;
4. отражатель;
5. 3 разнесённые частоты, обязательно включая 24.125 ГГц;
6. угол;
7. backscatter/RCS ratio.

Физический VNA-эксперимент сопоставляется с Meep на 24.125 ГГц.

## Динамическая демонстрация

Если успеваем, линза устанавливается на Mavic. БПЛА приближается к наземному радару и удаляется, как требовал эксперт.

Этот опыт показывает применимость конструкции в реальном движении, но количественное доказательство ×10 берётся из стационарного VNA-измерения.

## Что считать успешным результатом

Минимум:

- VNA уверенно различает BACKGROUND и METAL Ø80 мм на рабочей дистанции;
- получены повторяемые комплексные S21;
- выполнено фоновое вычитание/time gating;
- получена `Delta_sigma_dB` для METAL vs LENS_METAL;
- снята угловая зависимость;
- результат сопоставлен с Meep.
