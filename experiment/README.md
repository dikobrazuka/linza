# Экспериментальный стенд и методика

## Цель

Проверить **одну и ту же линзу на нескольких частотах** и для каждой частоты отдельно сравнить радиолокационный отклик:

- без линзы;
- с линзой.

Основной сценарий движения остаётся заданным экспертом:

- приближение к радару;
- удаление от радара;
- движение строго по оси;
- без бокового пролёта.

## Ключевой принцип сравнения

Нельзя напрямую сравнивать абсолютную амплитуду сигнала разных радарных модулей, потому что у них различаются:

- мощность передатчика;
- усиление антенн;
- чувствительность приёмника;
- диаграмма направленности;
- внутренний усилитель.

Поэтому на каждой частоте считаем свой относительный эффект:

`G(f) = отклик с линзой / отклик без линзы`

или в дБ:

`Δ(f) = 20 log10(A_lens/A_base)` для измеренной амплитуды IF,

а для величины, пропорциональной мощности, использовать 10 log10.

На защите итог должен выглядеть как таблица:

| Частота | Без линзы | С линзой | Относительный прирост |
|---:|---:|---:|---:|
| f1 | ... | ... | ... дБ |
| f2 | ... | ... | ... дБ |
| f3 | ... | ... | ... дБ |

## Рекомендуемые частотные точки для дешёвого стенда

### Минимум — две частоты

1. **10.525 ГГц — HB100**
2. **24.125 ГГц — CDM324**

Оба модуля являются готовыми CW Doppler radar front-end с передатчиком, приёмником и IF-выходом. Это самый простой вариант доказать работу линзы на разных частотах без VNA.

### Лучше — три частоты

Добавить промежуточную точку около **5.8 ГГц** с модулем, у которого доступен аналоговый IF-выход (например подходящий модуль семейства AT58L4LDB/аналог).

Не использовать RCWL-0516 как главный количественный канал: у дешёвых плат частота плохо нормирована, а штатный OUT является цифровым детектором движения, поэтому честное сравнение амплитуды затруднено.

## Почему разные частоты важны

Идеальная линза Люнеберга по своей концепции широкополосна, но реальная FDM-реализация ограничивается:

- электрическим размером D/λ;
- дискретизацией на зоны;
- размером ячеек заполнения относительно λ;
- дисперсией материала;
- технологическими ошибками;
- положением и размером металлического отражателя.

Для линзы диаметром 80 мм:

| Частота | λ в воздухе | D/λ |
|---:|---:|---:|
| 5.8 ГГц | ≈51.7 мм | ≈1.55 |
| 10.525 ГГц | ≈28.5 мм | ≈2.81 |
| 24.125 ГГц | ≈12.4 мм | ≈6.44 |

Поэтому один и тот же образец должен давать разные количественные результаты на разных частотах — это и является частью исследования.

## Базовая архитектура стенда

Для каждой частоты используется отдельный Doppler radar module, но механика и обработка остаются одинаковыми:

`Radar module -> IF amplifier -> ADC/oscilloscope/Arduino -> laptop`

Радар жёстко закреплён в одной точке. Цель на неметаллической каретке движется к радару и от него по одной и той же трассе.

## Механика

### Радар

- крепится жёстко;
- не меняет положение внутри серии;
- центр радара = высота центра линзы;
- направлен строго вдоль трассы.

При переходе на другую частоту заменяется только радарный модуль на том же креплении. Желательно сделать универсальный 3D-печатный держатель с одинаковой осью для всех модулей.

### Трасса

- прямая линия по оси радара;
- ориентировочно 1–5 м для первого стенда;
- разметка через 0.25–0.5 м;
- максимально убрать крупные металлические объекты вблизи трассы.

### Цель

Лучше использовать один и тот же БПЛА или макет БПЛА на одной и той же каретке.

Конфигурации:

1. `DRONE_BASE` — БПЛА без линзы;
2. `DRONE_LENS` — тот же БПЛА + линза;
3. полезно: `LENS_ONLY` и `REFLECTOR_ONLY` для диагностики.

Между сериями запрещено менять ориентацию БПЛА.

## Электронная часть

### 10.525 ГГц

HB100 -> low-noise IF amplifier -> ADC.

HB100 имеет слабый IF-сигнал, поэтому нужен усилитель.

### 24.125 ГГц

CDM324 -> IF amplifier/ADC.

CDM324 имеет собственный IF-выход и может использоваться по той же логике.

### 5.8 ГГц, если добавляется

Использовать модуль только если у конкретной платы документирован аналоговый IF-выход. Схема обработки должна оставаться максимально аналогичной остальным частотам.

## Как сравнивать частоты честно

Для каждой частоты проводить отдельную серию:

1. прогреть радар;
2. записать фон;
3. 5 приближений `DRONE_BASE`;
4. 5 приближений `DRONE_LENS`;
5. 5 удалений `DRONE_BASE`;
6. 5 удалений `DRONE_LENS`;
7. рассчитать относительный прирост на этой частоте.

Только после этого переходить на следующий радар.

## Скорость движения

Желательно одинаковая во всех сериях. Доплеровская частота зависит от скорости, поэтому скорость должна быть либо:

- задана мотором/лебёдкой;
- либо измеряться по видео/меткам и использоваться при обработке.

## Что измерять

Для каждой частоты:

- RMS/peak амплитуду IF;
- SNR относительно фона;
- дальность первого устойчивого обнаружения;
- дальность потери обнаружения;
- отношение `LENS / BASELINE`.

## Угловой эксперимент

После осевых прогонов на каждой частоте можно зафиксировать цель на одной дистанции и снять:

- -20°;
- -15°;
- -10°;
- -5°;
- 0°;
- +5°;
- +10°;
- +15°;
- +20°.

Это показывает, насколько отражатель сохраняет работу при ошибке ориентации.

## Связь с Meep

В Meep один и тот же физический образец рассчитывать минимум на тех же частотах, что используются в эксперименте.

То есть при стенде HB100 + CDM324 обязательные расчётные точки:

- 10.525 ГГц;
- 24.125 ГГц.

При наличии 5.8-ГГц модуля добавить 5.8 ГГц.

Не оптимизировать отдельную геометрию под каждую частоту, если задача эксперта — доказать широкополосность **одной конструкции**. Сначала проверяется одна геометрия во всём наборе частот.

## Итоговый график

Главный итог защиты:

`Относительный прирост радиолокационного отклика, дБ` vs `частота`.

Дополнительно:

- дальность обнаружения vs частота;
- угловая характеристика на каждой частоте;
- Meep vs эксперимент.
