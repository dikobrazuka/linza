# BUILD MANUAL — собрать стенд с нуля

Этот файл должен позволить собрать стенд без самостоятельного проектирования схемы.

## 0. Что в итоге должно получиться

Один измерительный комплект с тремя сменными радиомодулями:

1. RCWL-0516 — около 3.2 ГГц;
2. HB100 — 10.525 ГГц;
3. CDM324/IPM-165 — около 24.125 ГГц.

Общий тракт:

`радар -> аналоговый Doppler/IF -> усилитель (где нужен) -> Arduino Nano A0 -> USB -> ноутбук -> CSV`

Два режима испытания:

- стационарный контролируемый: линза на фиксированной дистанции совершает небольшое повторяемое движение вдоль оси радара;
- натурный: тот же образец закреплён на Mavic, БПЛА приближается к радару и удаляется.

# 1. Купить до начала сборки

## 1.1 Радиомодули

- RCWL-0516 — 2 шт.;
- HB100 — 2 шт.;
- CDM324 / IPM-165, 3-контактная версия VCC/IF/GND — 2 шт.

Второй экземпляр каждого — запасной.

## 1.2 Управление и питание

- Arduino Nano CH340 — 1 шт.;
- USB-кабель — 1;
- powerbank 5 В или качественный USB БП — 1;
- отдельный БП 5 В 1–2 А для сервопривода — 1;
- SG90/MG90S — 1 шт. + 1 запасной.

## 1.3 Аналоговая электроника

- LM358 DIP-8 — 4 шт.;
- панельки DIP-8 — 4 шт.;
- breadboard 830 точек — 1;
- монтажная плата 5×7 см — 3 шт.;
- Dupont-провода;
- тонкий монтажный провод;
- эмалированный провод 0.2–0.3 мм для RCWL.

Резисторы, 0.25 Вт, минимум по 10 шт.:

- 1 кОм;
- 10 кОм;
- 100 кОм;
- 200 кОм;
- 470 кОм;
- 1 МОм;
- 12 кОм.

Конденсаторы:

- 100 пФ — 10;
- 1 нФ — 10;
- 2.2 нФ — 10;
- 100 нФ — 20;
- 1 мкФ — 10;
- 4.7 мкФ — 10;
- 47 мкФ — 5;
- 100 мкФ — 5.

## 1.4 Механика стационарного опыта

- фотоштатив или самодельная стойка радара;
- отдельная стойка образца;
- ПВХ/стеклопластиковая трубка 0.5–1 м;
- тонкая капроновая леска;
- PLA/PETG для держателей;
- рулетка;
- металлическая контрольная мишень примерно 150×150...200×200 мм.

## 1.5 Инструмент

- паяльник с тонким жалом;
- припой;
- флюс;
- мультиметр;
- бокорезы;
- пинцет;
- термоусадка;
- лупа/макрокамера телефона;
- штангенциркуль;
- весы.

# 2. Сначала Arduino — без радаров

1. Подключить Nano по USB.
2. Установить Arduino IDE.
3. Если плата не определяется — установить CH340 driver.
4. Выбрать `Arduino Nano`, правильный COM-порт и процессор платы.
5. Загрузить `Blink`.
6. LED должен мигать.

Критерий перехода: Arduino стабильно прошивается и Serial Monitor работает на 115200 baud.

---

# 3. Общая аналоговая часть

Для HB100 и CDM324 использовать отдельные усилительные платы. Не переключать разные радары на одной breadboard во время финальных измерений.

## 3.1 Распиновка LM358 DIP-8

При выемке/точке корпуса сверху:

```
        LM358
     +---------+
OUT1 |1       8| V+
-IN1 |2       7| OUT2
+IN1 |3       6| -IN2
 GND |4       5| +IN2
     +---------+
```

## 3.2 Питание LM358

- pin 8 -> +5 В;
- pin 4 -> GND;
- 100 нФ непосредственно между pin 8 и pin 4.

## 3.3 VREF = 2.5 В

Собрать делитель:

`+5V -> 10k -> VREF -> 10k -> GND`

На VREF поставить:

- 47 мкФ на GND;
- 100 нФ на GND.

До подключения радара мультиметром проверить:

- между +5V и GND: 4.8–5.2 В;
- VREF: примерно 2.4–2.6 В.

Если этого нет — дальше не идти.

---

# 4. RCWL-0516 — канал около 3.2 ГГц

RCWL штатно выдаёт только цифровой `OUT`, которого недостаточно для сравнения амплитуды. Нужен аналоговый сигнал с выхода второго внутреннего ОУ RCWL-9196 — pin 12 / XOUT.

## 4.1 Сначала проверить штатную плату

Подключить:

- VIN -> +5 В;
- GND -> GND Arduino;
- OUT -> D2 Arduino.

Важно: `3V3` на RCWL — выход питания, не вход.

После включения подождать несколько секунд и двигать рукой перед компонентной стороной платы.

Критерий исправности:

- без движения OUT около 0 В;
- при движении OUT около 3.3 В.

## 4.2 Подпаять аналоговый XOUT

1. Полностью снять питание.
2. Найти 16-выводную микросхему RCWL-9196.
3. Найти метку pin 1.
4. Нумерация идёт против часовой стрелки.
5. Нужен pin 12 — выход второго ОУ.
6. Взять эмалированный провод 0.2–0.3 мм.
7. Облудить только его конец.
8. Нанести немного флюса на pin 12.
9. Коротким касанием припаять провод.
10. Мультиметром в режиме прозвонки проверить отсутствие КЗ с соседними ножками.
11. Закрепить провод каплей термоклея/УФ-клея на плате, чтобы нагрузка не приходилась на ножку IC.

Подключение к Arduino:

`RCWL pin12 -> 1k -> A0`

GND RCWL и Arduino общий.

RCWL pin12 в покое должен находиться около середины диапазона 3.3 В и изменяться при движении. Если используется Arduino Nano с 5-В АЦП, сигнал 0–3.3 В безопасен.

Критерий перехода: в Serial Plotter видны повторяемые колебания при движении металлической мишени перед датчиком.

---

# 5. HB100 — 10.525 ГГц

HB100 имеет очень слабый IF, поэтому напрямую на A0 его не подключать.

## 5.1 HB100 питание

Ориентироваться по маркировке конкретной платы `VCC / GND / IF`.

- VCC -> +5 В;
- GND -> общий GND;
- IF -> вход усилителя.

Около HB100 поставить:

- 100 нФ между VCC и GND;
- 100 мкФ между VCC и GND.

Не подавать питание, пока VCC/GND не проверены мультиметром.

## 5.2 Усилитель HB100

Использовать двухкаскадный усилитель. Для студенческого стенда собираем версию с VREF 2.5 В и общим усилением около 1000.

### Каскад 1

Вход:

`HB100 IF -> 1 мкФ -> node S1`

`node S1 -> 100 кОм -> VREF`

`node S1 -> LM358 pin 3 (+)`

Инвертирующая цепь:

`pin 2 -> 10 кОм -> VREF`

Обратная связь:

`pin 1 -> 470 кОм -> pin 2`

Параллельно 470 кОм поставить 100 пФ.

Усиление примерно 48.

### Каскад 2

`pin 1 -> pin 5 (+)`

`pin 6 -> 10 кОм -> VREF`

`pin 7 -> 200 кОм -> pin 6`

Параллельно 200 кОм поставить 100 пФ.

Усиление примерно 21.

Общий коэффициент около 1000.

Выход:

`pin 7 -> 1 кОм -> Arduino A0`

### Проверка без радара

До соединения IF:

- pin 1 должен быть около VREF;
- pin 7 должен быть около VREF;
- A0 должен быть около 2.5 В / ~512 ADC.

Если выход сидит около 0 В или 5 В — искать ошибку монтажа, радар пока не подключать.

### Проверка с HB100

1. Подключить IF.
2. Поставить металлическую мишень на 1–2 м.
3. Двигать мишень вдоль оси радара.
4. Смотреть A0/Serial Plotter.

Если сигнал клиппируется в 0/1023 — временно брать выход первого каскада pin 1 или уменьшить 470 кОм до 200 кОм.

Критерий перехода: без движения среднее близко к середине АЦП; при движении есть стабильная переменная составляющая без постоянного клиппинга.

---

# 6. CDM324 / IPM-165 — около 24.125 ГГц

Для стандартного трёхконтактного IPM-165:

- pin 1 = VCC 4.75–5.25 В;
- pin 2 = IF1;
- pin 3 = GND.

Перед пайкой сравнить расположение pin 1 с маркировкой/рисунком именно приобретённой платы.

## 6.1 Питание

- pin 1 -> +5 В;
- pin 3 -> GND;
- около модуля 100 нФ + 100 мкФ между питанием и землёй.

## 6.2 Усилитель CDM324

Так как IF у этого модуля существенно больше, чем у HB100, использовать один каскад с умеренным усилением.

Вход:

`IF pin2 -> 1 мкФ -> node C1`

`node C1 -> 100 кОм -> VREF`

`node C1 -> LM358 pin 3 (+)`

Инвертирующая цепь:

`pin 2 -> 10 кОм -> VREF`

Обратная связь:

`pin 1 -> 100 кОм -> pin 2`

Параллельно 100 кОм поставить 100 пФ.

Усиление примерно 11.

Выход:

`pin 1 -> 1 кОм -> A0`

Если сильная мишень вызывает клиппинг — заменить 100 кОм обратной связи на 47 кОм (усиление ~5.7).

Если сигнал слишком мал — заменить на 200 кОм (усиление ~21).

На финальной серии выбранный резистор зафиксировать и больше не менять между BASELINE/LENS.

---

# 7. Код Arduino — сначала сырой поток

Первый тест делать без сложной обработки. Читать A0 с частотой около 5 кГц и отправлять в Serial.

После подтверждения работы перейти на запись CSV с колонками:

`time_ms, radar, configuration, run, adc_raw`

Для финальной обработки рассчитывать:

- среднее;
- AC RMS после удаления DC;
- спектральный Doppler peak;
- SNR относительно фонового участка.

Частота дискретизации 5 кГц достаточна для основной студенческой проверки при умеренной скорости Mavic; если реальные Doppler-компоненты подходят к пределу Найквиста, увеличить до 10 кГц.

---

# 8. Стационарный стенд — механика

Цель: получить повторяемое движение только образца на фиксированной средней дистанции.

## 8.1 Расстановка

Начать с дистанции 2–3 м:

`RADAR ---------------- 2...3 м ---------------- SAMPLE`

Центры радара и линзы на одной высоте.

Радар на штативе. Образец на отдельной неметаллической стойке/ползунке.

## 8.2 Как двигать образец

Не ставить сервопривод рядом с образцом в луче радара.

Серво разместить за радаром или заметно вне основного луча. От него пустить тонкую капроновую леску к пластиковому ползуну образца.

Ход образца для первого теста: примерно 40–60 мм пик-пик вдоль оси радара.

Скорость/частота движения должна быть одинаковой для всех конфигураций.

Пример режима:

- движение вперёд примерно 0.5 с;
- движение назад примерно 0.5 с;
- непрерывно 20–30 с.

Конкретную амплитуду движения измерить линейкой и больше не менять.

## 8.3 Конфигурации

Снимать минимум:

1. `HOLDER` — только держатель;
2. `LENS_NO_METAL` — линза без отражателя;
3. `METAL_ONLY` — отражающий сектор на лёгком диэлектрическом носителе;
4. `LENS_METAL` — финальная линза с отражающим сектором.

Это позволяет показать, что результат не сводится к простому кусочку фольги.

На каждой частоте и каждой конфигурации минимум 5 записей по 20–30 с.

---

# 9. Перед каждым измерением

1. Поставить нужный радар.
2. Проверить питание мультиметром.
3. Включить систему.
4. Дать электронике стабилизироваться несколько минут.
5. Никому не двигаться перед радаром.
6. Записать 20–30 с фона.
7. Включить движение образца.
8. Записать 20–30 с.
9. Остановить.
10. Сохранить CSV сразу с понятным именем.

Пример:

`10p525GHz_LENS_METAL_run03.csv`

---

# 10. Что считается исправным результатом стационарного этапа

До полёта на Mavic должны быть выполнены все пункты:

- все три радара отдельно дают повторяемый сигнал на металлической контрольной мишени;
- нет клиппинга ADC;
- фон минимум в несколько раз ниже сильной контрольной мишени;
- 5 повторов одной конфигурации похожи друг на друга;
- после возвращения к исходной конфигурации уровень возвращается примерно к прежнему;
- `LENS_METAL` можно сравнить с `HOLDER`, `METAL_ONLY` и `LENS_NO_METAL`.

Если этого нет — к полётному эксперименту не переходить.

---

# 11. Крепление на Mavic

До проектирования адаптера определить конкретную модель Mavic.

Правила адаптера:

- не закрывает камеры/датчики;
- не входит в диск винтов;
- не мешает подвесу камеры;
- не закрывает вентиляцию;
- не мешает складыванию лучей во время установки/снятия;
- не имеет свободно болтающихся деталей;
- имеет страховочный мягкий ремешок;
- масса всей добавки измеряется до полёта.

Первый полёт делать не с финальной линзой, а с балластом той же массы и приблизительно того же расположения центра масс.

---

# 12. Полётный эксперимент

Для каждой частоты:

1. Радар поставить неподвижно на штатив.
2. Подключить тот же усилитель и Arduino, что прошли стационарную проверку.
3. Записать фон.
4. Выполнить несколько прямолинейных проходов `MAVIC_BASELINE` к радару и от него.
5. Поставить линзу.
6. Повторить максимально похожие проходы `MAVIC_LENS`.
7. Одновременно снимать полёт сбоку на смартфон; в кадре должны быть ориентиры расстояния.
8. Сохранить телеметрию Mavic, если она доступна.
9. Сравнивать BASELINE/LENS на одной частоте, а не абсолютные уровни между тремя разными радарами.

---

# 13. Что НЕ менять внутри парного сравнения

Между BASELINE и LENS на одной частоте не менять:

- положение радара;
- высоту радара;
- ориентацию антенны;
- усилитель;
- коэффициент усиления;
- питание;
- Arduino/ADC;
- алгоритм обработки;
- направление полёта;
- по возможности скорость и высоту БПЛА.

---

# 14. Главный результат

Стационарный этап:

- `RMS_LENS / RMS_BASELINE`;
- SNR;
- повторяемость;
- частотная зависимость.

Полётный этап:

- относительный уровень Doppler-отклика с/без линзы;
- дальность устойчивого обнаружения с/без линзы;
- повторяемость по нескольким проходам.

Дешёвый стенд не использовать для заявления абсолютной ЭПР в м² без отдельной RCS-калибровки.

---

# 15. Контрольный порядок — делать именно так

1. Купить электронику.
2. Проверить Arduino.
3. Проверить RCWL штатным OUT.
4. Подпаять RCWL analog pin12 и проверить его.
5. Собрать VREF.
6. Собрать HB100 усилитель без радара, проверить DC-уровни.
7. Подключить HB100 и металлическую мишень.
8. Собрать CDM324 усилитель без радара, проверить DC-уровни.
9. Подключить CDM324 и металлическую мишень.
10. Перенести работающие усилители с breadboard на монтажные платы.
11. Повторно проверить все три канала.
12. Собрать стационарный ползунок образца.
13. Подключить привод через леску, серво оставить вне луча.
14. Проверить HOLDER.
15. Проверить металлическую контрольную мишень.
16. Проверить LENS_NO_METAL.
17. Проверить METAL_ONLY.
18. Проверить LENS_METAL.
19. Обработать данные и убедиться в повторяемости.
20. Только теперь проектировать адаптер под конкретный Mavic.
21. Провести полёт с балластом.
22. Провести BASELINE.
23. Провести LENS.
24. Повторить для трёх частот.
25. Свести результаты с Meep.
