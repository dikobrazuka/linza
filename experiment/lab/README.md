# LINZA: локальный лабораторный журнал

Запуск в Windows: дважды нажмите `Запустить лабораторию.bat` и оставьте его окно
открытым. Браузер откроет `http://127.0.0.1:8765/`. Если ссылка не открылась,
введите этот адрес вручную. Закрытие окна завершает локальный сервер.

Страница хранит записи и отметки в localStorage **конкретного браузера**. Для
резервной копии и переноса нажмите «Сохранить журнал»; исходные измерительные
файлы (.s2p и др.) нужно хранить отдельно, в журнале записываются пути и заметки.
Генератор сохраняет STL и CSV в `exports/lab`, используя уникальные имена.

Программа использует текущие генераторы проекта, а не облачный сервис. В этом
рабочем пространстве стартовый Python лежит в bundled runtime Codex, а библиотеки
в `exports/plan_b_200mm/python_deps`. На другом компьютере доступны Python с
`numpy`, `scikit-image` и `trimesh` в стандартном окружении; запустите
`python experiment/lab/server.py`. Без Python страница может показывать форму,
но STL не создаст. Интернет для работы не нужен.

Частоты, лабораторная оснастка и валидность измеренных epsilon должны быть
подтверждены отдельно. CSV генератора для линзы не включает сплошную подложку;
отрезание наружного диапазона по `rho_min` меняет идеальный профиль. Одной
замкнутости STL недостаточно для гарантии FDM-печати. Расчёт S21 предполагает
комплексные линейные значения и одинаковую калибровку; уровень шума отдельно
оценивает экспериментатор.
