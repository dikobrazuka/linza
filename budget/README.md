# Смета стенда — текущий статус

## ВАЖНО

Финальный эксперимент проекта должен выполняться на **трёх рабочих частотах из презентации**:

- **2 ГГц**;
- **3 ГГц**;
- **8.5 ГГц**.

Поэтому предыдущая идея построить финальный стенд вокруг HB100 10.525 ГГц **не соответствует постановке проекта**.

HB100 можно использовать только как дешёвый отладочный модуль для проверки:

- механики трассы;
- каретки;
- алгоритма приближения/удаления;
- усилителя/АЦП;
- логирования данных.

Но покупать его как основной измерительный канал пока не нужно.

## Что пока НЕ покупать

До выбора единой RF-архитектуры для 2 / 3 / 8.5 ГГц не покупать:

- три случайных radar module;
- HB100 как финальный радар;
- отдельные дорогие рупоры;
- VNA;
- СВЧ-генераторы;
- усилители неизвестного диапазона;
- фильтры под несогласованные частоты.

## Следующая задача по смете

Нужно подобрать **одну недорогую перестраиваемую RF-архитектуру**, способную последовательно работать на 2, 3 и 8.5 ГГц, чтобы:

1. источник и приёмник не менялись целиком между сериями;
2. менялась только частота/антенна или минимальное число компонентов;
3. сохранялась одинаковая методика приближения/удаления;
4. стоимость оставалась реалистичной для студенческого проекта.

После выбора этой архитектуры сюда добавляется точная закупочная ведомость по Казани.
