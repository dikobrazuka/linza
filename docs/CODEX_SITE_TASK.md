## Выполни теперь

1. **Сверь текущий main**, не откатывай последние коммиты. Просмотри текущую работу сайта `site/index.html`, `site/board.html`, `site/explain.html`; тестировать взаимодействия в браузере, desktop и mobile. Не ограничивайся «CSS красиво».
2. **Убери удвоение WBS**: канонические `site/data/actions.json` и пользовательский интерактивный WBS/канбан должны быть согласованы через стабильные IDs и явную миграцию. Существующие `linza-wbs-v1` и `linza-budget-v1` не стирать, бэкап перед импортом/миграцией, оставить импорт/экспорт.
3. **Сделай общую смету полноценной интерактивной таблицей** на основе `procurement.json`: поиск по позиции, фильтр направления/статуса, цена строки, количество, сумма, ссылка, комментарий; статус покупки отдельно от статуса действия. Показывать `24 267 ₽` + смолу отдельно `14 000 ₽` + TBD. Не умножать `line_total_rub` на `purchase_quantity` повторно.
4. **Собери работающую навигацию по процессу**: «Что купить → как спаять → как собрать 2 рупора → как откалибровать NanoVNA → как напечатать PLA Ø200 → как сделать DE10 Ø120 → как построить Ø80/24 и проверить на CDM324/лаборатории → как сохранить результаты». Каждая карточка должна иметь ссылку на конкретный протокол.
5. **Чётко отрази реальные статусы**: нет подтверждённых закупок, замеров, измеренной ЭПР или аппаратно проверенного OPA2365. Пользовательский localStorage не синхронизируется между членами команды, не обещай обратное.
6. Доработай UX без размножения страниц: современная, быстрая рабочая доска, поиск, раскрываемые подзадачи, чек-листы, responsive, доступная клавиатура, удобное открытие схем и CSV, результат и критерии GO/STOP.
7. Запусти `pytest -q`, `node --check site/work.js site/data-dashboard.js site/board-upgrade.js` (в цикле по файлам, потому что node --check принимает по одному), проверь JSON contract и Pages workflow; после изменения сайта проверь в живом браузере, а не только тесты.
8. **Не переписывай физику**. D-032 Ø200 только PLA, DE-10 остаётся Ø120, конечная Ø80/24. Калибровка NanoVNA на 383–483 МГц не годится для 5 ГГц. CDM324 ~24.125 ГГц — Doppler, не RCS. Контрольный сайт должен показывать эти ограничения.

## Критерий готовности
Пользователь на сайте может открыть заказ из 32 реальных строк, посмотреть актуальную смету и неизвестные статьи, пройти цепочку из 24 задач и открыть конкретные инструкции пайки/стенда/трёх образцов. Все формальные «готово» имеют реальное доказательство либо являются личной отметкой, не синхронизированной с командой. Изменения проходят CI, публикация Pages успешна, старые данные localStorage сохранены.

**Сначала коротко отчитайся об обнаруженных архитектурных проблемах и плане миграции, затем ВЫПОЛНИ правки в коде, проверь UI/CI и дай ссылки на коммиты/сайт.**
