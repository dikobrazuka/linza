# Ближайшие действия

## Сначала — не покупать всё сразу

### День 1

- [ ] Человек 1: установить Meep и запустить стандартный scattering example.
- [ ] Человек 3: купить/заказать **1× HB100 + 1–2× LM358 module + ESP32**.
- [ ] Человек 2: выбрать PLA/ABS и подготовить CAD тестовых infill-образцов.
- [ ] Создать общий каталог фото и начать фиксацию.

### После получения радара

- [ ] Собрать HB100 -> amplifier -> ESP32/осциллограф.
- [ ] Проверить, что человек, металлическая пластина и печатная деталь дают различимый Doppler signal.
- [ ] Измерить реальную стабильность и рабочую дальность.
- [ ] Зафиксировать фактическую частоту модуля для расчётной модели (номинально HB100 10.525 ГГц).

### После рабочего радара

- [ ] Человек 1 пересчитывает Ø80 мм модель на фактическую частоту.
- [ ] Найти фокус.
- [ ] Сделать 6 зон.
- [ ] Подобрать отражающий сектор.

### Параллельно

- [ ] Человек 2 печатает infill-образцы.
- [ ] Делает CAD двух полусфер/сегментов и крепления.
- [ ] Проверяет массу в слайсере.

### Затем

- [ ] Собрать неметаллическую каретку.
- [ ] Разметить трассу.
- [ ] Сделать baseline.
- [ ] Напечатать LENS_V1.
- [ ] Провести первую сравнительную серию.

## Минимальный результат первой итерации

Не ждать финальной конструкции. Первая итерация считается успешной, если есть:

1. работающий HB100 с записью IF-сигнала;
2. движение цели по оси даёт воспроизводимый сигнал;
3. Meep показывает фокус Ø80 мм линзы;
4. напечатана хотя бы тестовая многозонная конструкция;
5. есть первый график `BASELINE vs LENS_V1`.

После этого уже оптимизировать, а не проектировать всё заново.
