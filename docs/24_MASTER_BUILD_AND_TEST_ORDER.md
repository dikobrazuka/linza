# Операционный план: от коробки с деталями до отчёта

Версия PLAN-R1 / 09.11.2026. Срок сдачи, названный в обсуждении, **18 ноября 2026**. Это рабочая последовательность и контрольные критерии, а **не обещание**, что недостающая смола/измерители приедут вовремя. Работать параллельно несколькими потоками.

## Дерево проекта — единственный маршрут

```text
СМЕТА/ПОСТАВКИ ──┬──> 5 ГГц ──> 2 РУПОРА ──> NANOVNA SOLT ──> BACKGROUND/REFERENCE
                │                                  │
                │               ┌──────────────────┴───────────────────────┐
                │               │                                          │
                ├──> PLA Ø200/FDM: CAD ─> купоны ─> печать ─> P0..P5 ─> Δ/RCS proxy
                │
                ├──> DE-10 Ø120: T1/T2/T3/T4 ─> measured ε ─> Meep/M9 ─> печать ─> D0..D5
                │
                ├──> Ø80/24 ГГц: отдельный M10, mass/geometry, physical RF validation в лаборатории
                │
                └──> CDM324: правильное VCC/IF ─> AFE OPA2365 ─> Pico ADC ─> moving plate
                                                                   │
                                                          только затем DJI/FPV
```

## Назначение ролей для команды из 3 человек

| Поток | Исполнитель A | Исполнитель B | Исполнитель C |
|---|---|---|---|
| CAD/изготовление | PLA Ø200, половины, держатели, печать | DE10 купоны и процесс + CAD T4 | два рупора + механический RF стенд |
| Электроника/ВНА | помогает CAD оснастки | CDM324+OPA2365+Pico, пайка/контроль | NanoVNA SOLT, S11/S21, калибровка |
| Расчёты/доказательства | Meep PLA200, фото/геометрия | DE10 measured law, Meep Ø120 | Ø80/M10, журналы RF, обработка и общий отчёт |

Роли можно поменять по наличию оборудования. **Нельзя одновременно менять калибровку и геометрию в ходе одной серии.**

## План по порядку, с жёсткими переходами

### Этап 0. Приёмка закупки

- [ ] Сверить с budget/MASTER_BOM_AND_COST_2026-11-09.md: фактически заказано/доставлено, count, модель, фото маркировки/упаковки, цена, ссылка.
- [ ] Проверить фактические корпус OPA2365 SOIC8, подходящий SOIC8→DIP8, нить 28AWG, ёмкости 22n/100n, Pico Micro-USB data, комплект VNA calibration.
- [ ] Найти припой, flux, мультиметр, по возможности осциллограф; при отсутствии задержать включение сомнительного усилителя.
- [ ] Определить поставку DE-10, доступный MSLA/DLP, наличие двух компонентов материал/технология.

### Этап 1. Пайка и проверка CDM324 — строго по контрольным точкам

- [ ] Фото платы CDM324, определить **VCC/GND/IF именно этой ревизии** и паспортное питание.
- [ ] OPA2365 паять на адаптер; затем компоненты и соединения по electronics/01 и CSV netlist.
- [ ] Прозвонка +3V3/GND, соседних выводов U1 и RC-сетей без питания.
- [ ] Pico USB power, U1.8≈3.3V, VREF≈1.65V, U1.1/U1.7 ≈1.65V. ADC0 подключать только при пределах 0–3.3V; осциллографом проверить высокочастотную устойчивость.
- [ ] Radar VCC только после паспорта, IF через RG174. Проверка металлической пластиной при радиальном перемещении на размеченном расстоянии.
- [ ] Записать не менее 3 повторных raw/FFT серий и фон; не перепутать измеренное изменение IF с RCS.

### Этап 2. Рупоры и 5-ГГц стенд

- [ ] Проверить SMA-7814-16 как механический аналог Amphenol 2950-6061 по STEP (длина центрального контакта и крепление); при необходимости поправить CAD.
- [ ] Напечатать 2 рупора и 2 задние пластины, металлизировать поверхности и гребни, проверить геометрические контакты, фото внутри.
- [ ] Две стойки + низкорассеивающий держатель + поворотная шкала, затем зафиксировать антенны и кабели.
- [ ] На NanoVNA-F V3 ввести **около 5 ГГц**, сделать SOLT на концах измерительных 5D-FB, не использовать старую калибровку 383–483 МГц.
- [ ] S11 по каждому рупору, S21 контроль пары; BACKGROUND, HOLDER, REFERENCE и проверка прямой связи.
- [ ] **STOP**, если REFERENCE и проектный baseline неотделимы от фона, или S11 неустойчив от касания кабеля.

### Этап 3. PLA/FDM №1 Ø200 мм

- [ ] Выбрать конкретную марку PLA и ε/физику infill; реальные RF coupons, slicing/доступность Ø200×100 мм полусфер.
- [ ] Две полусферы, отражатель, шов/клей, измерить массу/размеры и фото каждого этапа.
- [ ] Отдельный Meep ideal Ø200 и затем manufacturable PLA model (не применять DE10 константы без оговорки).
- [ ] При 2/2.5/3 м выбрать рабочую геометрию, выполнить P0..P5, ≥3 независимые установки baseline и test.
- [ ] Сохранить комплексные .s2p и результат Δ(f) только при стабильном background/reference.

### Этап 4. DE10/MSLA №2 Ø120 мм

- [ ] T1 solid epsilon/loss; T2 cured density; T3 printability; T4 measured ε_eff(rho,f), зафиксировать resin batch.
- [ ] Материальный gate по измеренным значениям, Meep Ø120; затем моделировать/печатать open hemispheres и wash/post-cure.
- [ ] Измерить D0..D5 на том же 5-ГГц стенде (1/1.25/1.5 м только старт), ≥3 постановки; T5 оболочку сравнить отдельно, если есть.
- [ ] Не выдавать manufacturer ε@10 ГГц за собственный RF результат на 5 ГГц.

### Этап 5. Заказная №3 Ø80 мм / 24 ГГц

- [ ] Провести самостоятельное моделирование ε(r), потерь, отражателя и оболочки (M10) и оценить массу/изготовимость, ≥3 материальных сценария.
- [ ] Реально печатать/собирать Ø80 только после CAD+GO. Проверить массу всей сборки ≤300 г.
- [ ] Для CDM324: зарегистрировать стабильный IF на движущейся металлической мишени; DJI/FPV только после проверки дрона, payload, законного безопасного полёта и внешнего контроля дальности.
- [ ] Для доказательства ЭПР на 24 ГГц нужен калиброванный 24-ГГц RF стенд: если его нет, **статус физической RCS проверки — NOT DONE**, расчёт и CDM324 demo документировать отдельно.

### Этап 6. Отчёт и защита

- [ ] Все измерения с датой/частотой/приборами/настройками, фото, raw data и скриптом расчёта; никаких графиков «примерных измерений» без источника.
- [ ] Таблица для каждой линзы: ТРЕБОВАНИЕ / РАСЧЁТ / ФАКТ / РАСХОЖДЕНИЕ / статус; заполнение только подтверждёнными фактами.
- [ ] Для Δ>=+10 дБ указывать baseline, RCS geometry, фон, диапазон частот и неопределённость; «заметное изменение S21» не равно поверенной абсолютной ЭПР.
- [ ] Сохранить понятные для защиты фотографии пайки (до/после), металлораспределения рупора, 3D-печати, сборки, стенда и трёх разных образцов.

## Приоритет к 18.11, если чего-то физически нет

**Максимально возможный доказательный пакет:** CAD/печать PLA200, два работоспособных 5-GHz рупора и VNA контроль P0..P5, Meep M10 Ø80 + расчёты, CDM324 bench prototype с raw IF, отдельный честный статус DE10 T1..T4. Не придумывать результаты отсутствующего материала/оборудования. Всё дополнять по мере реальной готовности, не ждать завершения всех веток, чтобы оформлять фото и raw data.

### Оболочка: детализация T5

Для защитной оболочки PLA-Aero Pro выполнить печать и контроль не менее трёх образцов, согласовать RF-оснастку до изготовления RF-купонов и сравнить сборку без оболочки, с установленной оболочкой и с соединённым швом. Для Ø80/24 ГГц отдельно оценить влияние оболочки: измерение при 5 ГГц не подтверждает свойства на 24 ГГц. Порядок, контроль и ограничения — в [протоколе T5](18_PLA_AERO_SHELL_T5_PROTOCOL.md). Статус остаётся плановым до подтверждения результатами.
