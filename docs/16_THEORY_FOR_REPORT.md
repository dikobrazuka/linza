# Теоретическая часть для пояснительной записки и защиты

Дата: 2026-10-31

Этот текст рассчитан на прямое использование как основа теоретической главы проекта. Практическая часть вынесена отдельно в `docs/15_EXECUTABLE_PIPELINE.md`.

# 1. Назначение разработки

Цель проекта — разработать пассивную диэлектрическую градиентную линзу Люнеберга, изготовленную методом фотополимерной 3D-печати, и использовать её совместно с металлическим отражателем для увеличения обратного радиолокационного рассеяния объекта.

Основная идея заключается в том, что линза не создаёт радиосигнал самостоятельно. Она изменяет фазовое распределение падающей электромагнитной волны так, чтобы энергия концентрировалась вблизи противоположной поверхности линзы. Если в области фокуса расположен металлический отражатель, отражённая волна проходит через линзу в обратном направлении и формируется в направлении источника. За счёт этого увеличивается уровень обратного рассеяния.

Экспериментальная проверка выполняется на 5 ГГц. После подтверждения модели геометрия масштабируется для расчётного режима 24 ГГц.

# 2. Радиолокационная заметность и эффективная площадь рассеяния

Для количественного описания способности объекта рассеивать электромагнитную волну используется эффективная площадь рассеяния — ЭПР, или radar cross section, RCS.

В общем виде ЭПР определяется отношением мощности рассеянного поля в заданном направлении к плотности падающей мощности с приведением результата к площади.

Для дальнего поля:

`σ = 4π R² |E_s|² / |E_i|²`,

где:

- `σ` — ЭПР, м²;
- `R` — расстояние до точки наблюдения;
- `E_s` — напряжённость рассеянного поля;
- `E_i` — напряжённость падающего поля.

В логарифмической форме:

`σ_dBsm = 10 log10(σ / 1 m²)`.

В проекте основным показателем является не абсолютная ЭПР, а относительный прирост относительно металлического отражателя без линзы:

`K_sigma = σ_lens+reflector / σ_reflector`.

В децибелах:

`Delta_sigma_dB = 10 log10(K_sigma)`.

Так как измерительный тракт VNA регистрирует амплитуду электромагнитного поля через параметр `S21`, отношение ЭПР двух состояний при неизменной геометрии стенда можно определить как:

`K_sigma = |S21_test / S21_baseline|²`,

а следовательно:

`Delta_sigma_dB = 20 log10(|S21_test / S21_baseline|)`.

Целевой показатель проекта:

`Delta_sigma_dB >= +10 dB`,

что соответствует увеличению ЭПР не менее чем в 10 раз.

# 3. Принцип линзы Люнеберга

Линза Люнеберга относится к градиентным диэлектрическим линзам, или GRIN-структурам. В отличие от обычной линзы, где преломление в основном определяется формой внешней поверхности, в линзе Люнеберга коэффициент преломления изменяется непрерывно внутри объёма.

Для сферической линзы Люнеберга идеальное распределение относительной диэлектрической проницаемости задаётся выражением:

`ε_r(r) = 2 - (r/R)²`,

где:

- `r` — расстояние от центра линзы;
- `R` — радиус линзы.

В центре:

`ε_r(0) = 2`.

На поверхности:

`ε_r(R) = 1`.

При отсутствии магнитных материалов:

`μ_r ≈ 1`,

поэтому показатель преломления можно записать как:

`n(r) = sqrt(ε_r(r))`.

Таким образом:

`n(r) = sqrt(2 - (r/R)²)`.

Именно радиальное изменение `n(r)` заставляет лучи, проходящие через разные области линзы, накапливать различную фазовую задержку.

# 4. Почему появляется фокус

Фазовая скорость электромагнитной волны в диэлектрике равна:

`v_p = c / n`,

где `c` — скорость света в вакууме.

В областях с большим `ε_r` показатель преломления выше, а фазовая скорость ниже. Поэтому центральная часть волнового фронта, проходящая через более плотную область линзы, задерживается сильнее, чем часть фронта, проходящая ближе к внешней поверхности.

Накопленная фаза определяется выражением:

`φ = ∫ k0 n(s) ds`,

где:

`k0 = 2π/λ0`.

Профиль Люнеберга подобран таким образом, что эти различия фаз формируют сходящийся волновой фронт. Для плоской падающей волны идеальная сферическая линза фокусирует энергию около диаметрально противоположной точки своей поверхности.

Обратное преобразование также справедливо: источник, расположенный вблизи поверхности идеальной линзы, формирует после прохождения линзы приблизительно плоский выходной фронт.

Это свойство основано на взаимности электромагнитной системы.

# 5. Зачем нужен металлический отражатель

Сама диэлектрическая линза может рассеивать волну, однако её основное назначение в проекте — концентрация поля.

Падающая плоская волна:

`plane wave -> Luneburg lens -> focus`.

Если около фокуса расположить проводящий отражатель, происходит отражение электромагнитного поля. После обратного прохождения через линзу:

`reflector -> Luneburg lens -> approximately collimated return wave`.

Таким образом система работает как пассивный ретрорефлектор.

Для проекта сравниваются два состояния:

`BASELINE = reflector only`,

`TEST = lens + same reflector`.

Такое сравнение позволяет отделить эффект самой линзы от обычного отражения металлической детали.

# 6. Почему нельзя изготовить идеальный непрерывный диэлектрик напрямую

Идеальная линза требует изменения относительной диэлектрической проницаемости от 2 в центре до 1 на границе.

Обычный однородный фотополимер после отверждения имеет практически постоянную собственную диэлектрическую проницаемость `ε_solid > 2`.

Следовательно, получить требуемый профиль только изменением химического состава материала неудобно.

В проекте используется другой подход: изменяется доля твёрдого полимера и воздуха в локальном объёме.

В первом приближении:

`ε_eff = F(ρ, ε_solid)`,

где:

- `ρ` — объёмная доля полимера;
- `ε_solid` — диэлектрическая проницаемость сплошного полимера;
- `ε_eff` — эффективная диэлектрическая проницаемость ячеистой структуры.

При уменьшении доли полимера структура содержит больше воздуха, поэтому её эффективная диэлектрическая проницаемость приближается к 1.

При увеличении доли полимера `ε_eff` приближается к `ε_solid`.

# 7. Почему выбран sheet-gyroid

В качестве пространственной структуры выбран sheet-gyroid — одна из TPMS-геометрий, то есть структур на основе трижды периодических минимальных поверхностей.

Классическая функция gyroid:

`G(x,y,z) = sin(kx)cos(ky) + sin(ky)cos(kz) + sin(kz)cos(kx)`,

где:

`k = 2π/a`,

а `a` — период ячейки.

Sheet-gyroid задаётся условием:

`|G(x,y,z)| <= h`.

Параметр `h` определяет толщину sheet-структуры и, следовательно, объёмную долю материала.

Поэтому цепочка проектирования имеет вид:

`r -> ε_target(r) -> ρ(r) -> h(r) -> 3D geometry`.

То есть в проекте не создаются отдельные концентрические оболочки с разной плотностью. Плотность одной непрерывной gyroid-структуры изменяется плавно вместе с радиусом.

Преимущества такого подхода:

- непрерывная геометрия;
- отсутствие большого количества внутренних границ между зонами;
- возможность плавного изменения fill fraction;
- хорошая связность структуры;
- наличие открытых каналов, важных для удаления жидкой фотополимерной смолы;
- возможность изготовления одной геометрии с локально меняющейся эффективной диэлектрической проницаемостью.

# 8. Эффективная среда

Gyroid является неоднородной структурой на масштабе одной ячейки. Чтобы рассматривать её как условно однородный диэлектрик, размер ячейки должен быть существенно меньше длины волны внутри материала.

Для 5 ГГц:

`λ0 ≈ 60 mm`.

При номинальном периоде:

`a = 7.5 mm`,

получаем:

`λ0/a ≈ 8`.

В диэлектрике длина волны меньше:

`λ = λ0/sqrt(ε_eff)`.

Поэтому отношение `λ/a` также уменьшается.

Из-за этого gyroid нельзя считать идеально однородной средой автоматически. Именно поэтому эффективная диэлектрическая проницаемость должна быть подтверждена экспериментально на печатных образцах.

Для MVP используется экспериментальная зависимость:

`ρ_actual -> ε_eff`.

Она предпочтительнее чисто теоретической mixing-model зависимости.

# 9. Роль фотополимера DE-10

В проекте используется фотополимер HARZ Labs DE-10.

Имеющиеся данные производителя показывают относительную диэлектрическую проницаемость порядка `ε_r ≈ 2.3` на 10 ГГц, что выше максимального идеального значения линзы Люнеберга `ε=2`.

Это важно: центр линзы не требуется печатать сплошным полимером. Даже центральная область должна оставаться пористой, чтобы её эффективная проницаемость снизилась примерно до 2.

Для точного расчёта физической 5-ГГц модели используются собственные измерения материала около 5 ГГц.

# 10. Потери в диэлектрике

Реальный материал характеризуется комплексной диэлектрической проницаемостью:

`ε* = ε' - j ε''`.

Тангенс угла диэлектрических потерь:

`tanδ = ε''/ε'`.

Чем больше `tanδ`, тем больше электромагнитной энергии преобразуется в тепло при прохождении через материал.

Для линзы это приводит к уменьшению амплитуды поля в области фокуса и к снижению обратного рассеяния.

Поэтому в моделировании необходимо учитывать не только `ε'`, но и потери материала.

Для MVP достаточно:

1. получить значение `tanδ` около 5 ГГц;
2. проверить, что учёт измеренных потерь не уничтожает рассчитанный эффект.

# 11. Размер линзы и отношение D/lambda

При 5 ГГц:

`λ0 ≈ 59.96 mm`.

Для текущего образца:

`D = 120 mm`,

поэтому:

`D/λ0 ≈ 2`.

Это означает, что линза имеет размер всего около двух длин волн.

В такой области чистая геометрическая оптика уже недостаточна. Существенны:

- дифракция;
- конечный размер линзы;
- интерференция;
- размер и положение отражателя;
- период gyroid.

Поэтому результат должен подтверждаться полноволновым численным моделированием.

Для проекта используется FDTD-моделирование в Meep.

# 12. Полноволновое моделирование

Метод FDTD решает уравнения Максвелла во временной области на пространственной сетке.

Основные уравнения:

`∇ × E = -∂B/∂t`,

`∇ × H = ∂D/∂t + J`.

При линейном диэлектрике:

`D = ε0 ε_r E`.

В модели задаётся пространственное распределение:

`ε_r = ε_r(x,y,z)`.

Для идеальной линзы:

`ε_r(x,y,z) = 2 - (x²+y²+z²)/R²`

внутри сферы.

Численное моделирование позволяет получить:

- распределение электрического поля;
- положение фокуса;
- интенсивность поля;
- рассеянное поле;
- far-field response;
- ЭПР в направлении источника.

Meep вычисляет RCS через near-to-far преобразование: сначала рассчитываются поля на замкнутой поверхности около объекта, затем они пересчитываются в дальнюю зону.

# 13. Почему эксперимент проводится на 5 ГГц

Доступная измерительная установка работает до приблизительно 6 ГГц, поэтому экспериментальная проверка выполняется на 5 ГГц.

Такой подход позволяет:

- изготовить линзу достаточно крупного размера;
- измерить материал и структуру на той же частоте;
- проверить численную модель;
- затем использовать электромагнитное масштабирование для расчётной версии на 24 ГГц.

# 14. Масштабирование с 5 на 24 ГГц

Уравнения Максвелла обладают масштабной инвариантностью для геометрически подобных систем при одинаковых относительных свойствах материалов.

Если частота увеличивается с 5 до 24 ГГц, линейный масштаб равен:

`k = 5/24 ≈ 0.20833`.

Все линейные размеры уменьшаются в 4.8 раза:

`L_24 = L_5 * 5/24`.

Для текущей линзы:

- `D_5 = 120 mm`;
- `R_5 = 60 mm`;
- `a_5 = 7.5 mm`.

После масштабирования:

- `D_24 = 25 mm`;
- `R_24 = 12.5 mm`;
- `a_24 = 1.5625 mm`.

При идеальном электромагнитном подобии сохраняются:

- `D/λ`;
- `a/λ`;
- `r/R`;
- нормированный профиль `ε(r/R)`.

# 15. Ограничение масштабирования

Геометрическое масштабирование само по себе не гарантирует полного физического подобия.

С частотой могут изменяться:

- `ε_r` материала;
- `tanδ`;
- влияние шероховатости;
- относительный размер технологических дефектов;
- минимальная печатаемая толщина стенки.

Поэтому результат на 24 ГГц должен формулироваться как **расчётный прогноз**, основанный на экспериментально проверенной 5-ГГц модели.

Корректная формулировка:

> Физическая работоспособность конструкции проверяется на 5 ГГц. После сопоставления экспериментальных и численных результатов геометрически подобная конструкция рассчитывается для 24 ГГц с отдельным учётом возможной дисперсии и технологических ограничений.

# 16. Основная научно-техническая логика проекта

Полная причинно-следственная цепочка проекта:

`Luneburg law`

→ требуемый `ε(r)`

→ требуемая локальная volume fraction

→ изменение толщины sheet-gyroid

→ spatial gradient of effective permittivity

→ изменение фазовой скорости внутри линзы

→ формирование сходящегося волнового фронта

→ концентрация поля у противоположной поверхности

→ отражение металлическим reflector

→ обратное прохождение через линзу

→ формирование усиленного обратного рассеяния

→ увеличение RCS относительно reflector-only.

# 17. Что является вкладом проекта

Практический вклад заключается не в изобретении самой линзы Люнеберга, а в реализации её непрерывного радиального диэлектрического профиля средствами фотополимерной 3D-печати через TPMS sheet-gyroid и в экспериментальной проверке работы такой структуры на доступном 5-ГГц стенде.

Ключевые элементы:

1. переход от требуемого `ε(r)` к печатаемой локальной плотности;
2. использование одной непрерывной sheet-gyroid структуры вместо набора дискретных оболочек;
3. экспериментальная калибровка `ρ -> ε_eff`;
4. физическая проверка усиления обратного рассеяния;
5. масштабирование проверенной конструкции на 24 ГГц.

# 19. Короткий ответ на главный вопрос эксперта

**Почему линза должна увеличивать ЭПР?**

Потому что радиальный градиент диэлектрической проницаемости создаёт различную фазовую задержку для разных участков падающего волнового фронта. В результате плоская волна концентрируется в области противоположной поверхности. Металлический отражатель отражает поле из этой области, а при обратном прохождении через взаимную линзу отражённая волна преобразуется в направленный фронт в сторону источника. Поэтому при одинаковом отражателе система `линза + отражатель` возвращает в направлении радара больше мощности, чем `отражатель без линзы`.
