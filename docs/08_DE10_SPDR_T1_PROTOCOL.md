# T1 — DE-10: измерение εr и tanδ около 5 ГГц

Дата: 2026-10-30

Статус: готово к исполнению после получения DE-10 и подтверждения доступа к 5/5.1-GHz SPDR.

Цель: получить собственные значения `epsilon_r` и `tan(delta)` для сплошного HARZ DE-10 около рабочей частоты 5 ГГц. Эти значения заменят 10-GHz данные производителя в физически привязанной модели TEST_LENS_5G_V1.

## 1. Зафиксированный комплект образцов

Изготовить 4 одинаковые пластины:

- `DE10-S01`;
- `DE10-S02`;
- `DE10-S03`;
- `DE10-S04` — запасная.

Геометрия каждой пластины:

- `80.00 × 80.00 × 1.50 mm`;
- сплошное тело;
- без отверстий;
- без фасок;
- без рельефа и маркировки на рабочих поверхностях.

STL:

`DE10_SPDR_80x80x1p50.stl`

Основание выбора:

- IEC 61189-2-721:2015 для SPDR 5–6 ГГц указывает specimen size `80 × 80 mm`, maximum thickness `2.0 mm` и минимум 3 образца для room-temperature test;
- QWED для SPDR 5/5.1 ГГц указывает minimum sample `30 × 30 mm`, recommended size `65 mm`, maximum width `90 mm`, maximum thickness `1.95 mm`; следовательно `80 × 80 × 1.50 mm` находится внутри рабочего диапазона fixture;
- 1.50 mm выбрано как проектное значение: оно ниже ограничения fixture и уменьшает относительную ошибку измерения толщины по сравнению с очень тонкой пластиной.

Источники:

- IEC 61189-2-721:2015: https://standards.theiteh.com/catalog/standards/iec/424ab61f-04fc-4ab5-bee8-937a6b986e45/iec-61189-2-721-2015
- QWED SPDR: https://qwed.eu/measurement-setups/split-post-dielectric-resonators-spdr/

## 2. До основной печати

Не печатать S01–S04 до фиксации единого процесса.

Зафиксировать:

- printer model;
- wavelength: `405 nm`;
- layer height;
- normal exposure;
- bottom exposure;
- bottom layers;
- lift speed;
- wash medium;
- wash time;
- post-cure wavelength;
- post-cure time;
- post-cure temperature.

Сначала выполнить небольшой exposure/calibration print и после него зафиксировать профиль:

`PROFILE_DE10_V1`

После начала печати S01 менять параметры запрещено до завершения S04.

## 3. Печать

Все четыре образца печатать:

- из одной партии/бутылки DE-10;
- на одном принтере;
- одним профилем;
- с одинаковой ориентацией;
- одинаковой мойкой;
- одинаковой post-cure обработкой.

Ориентация: широкая плоскость пластины параллельна XY принтера; толщина 1.50 mm направлена по Z.

Расчётный геометрический объём одной пластины:

`80 × 80 × 1.5 = 9600 mm³ = 9.60 cm³`.

При ориентировочной плотности жидкой смолы `1.1 g/cm³` одна пластина содержит около `10.6 g` материала по геометрическому объёму. На 4 пластины резервировать около `42 g`, на весь T1 с calibration print и потерями — `50–60 g`.

## 4. Wash / post-cure

Для каждого образца записать:

- `wash_medium`;
- `wash_concentration`;
- `wash_1_min`;
- `wash_2_min`, если используется;
- `drying_min`;
- `cure_wavelength_nm`;
- `cure_time_min`;
- `cure_temperature_C`.

Все образцы обрабатывать одинаково.

После post-cure выдержать минимум 24 h перед RF-измерением в одинаковых условиях.

Для IEC-comparable conditioning целевой режим:

- `23 ± 2 °C`;
- `50 ± 5 % RH`;
- не менее `24 h`.

## 5. Контроль толщины

Инструмент: микрометр с разрешением `0.001 mm` или лучше.

На каждой пластине выполнить 9 измерений толщины в точках относительно центра:

- `(-25,+25)`;
- `(0,+25)`;
- `(+25,+25)`;
- `(-25,0)`;
- `(0,0)`;
- `(+25,0)`;
- `(-25,-25)`;
- `(0,-25)`;
- `(+25,-25)` mm.

Для каждой пластины вычислить:

- `t_mean`;
- `t_min`;
- `t_max`;
- `delta_t = t_max - t_min`.

Проектный pre-screen перед лабораторией:

- `1.40 mm < t_mean < 1.60 mm`;
- `delta_t <= 0.03 mm`;
- нет трещин;
- нет пузырей;
- нет липкой поверхности;
- нет выраженного коробления.

Если один из S01–S03 не проходит pre-screen, заменить его S04.

## 6. Контроль плоскостности и массы

Плоскостность: положить пластину без прижима на проверочную ровную поверхность/стекло. Зафиксировать наличие заметного отрыва углов или дуги.

Масса: весы `0.001 g`.

Записать массу каждого образца. Масса не участвует напрямую в SPDR-расчёте T1; она нужна для контроля воспроизводимости печати.

Физически:

- S01;
- S02;
- S03;
- S04 spare.

Файлы/таблицы:

- таблица 9 толщин для каждого образца;

Техническое задание оператору:

> Измерить относительную диэлектрическую проницаемость εr и тангенс диэлектрических потерь tanδ фотополимера HARZ DE-10 методом split-post dielectric resonator на номинальной частоте 5 или 5.1 ГГц. Использовать три независимых физических образца 80×80×1.50 мм. Для оценки повторяемости выполнить три независимые установки каждого образца в fixture.

## 8. Последовательность SPDR-измерения

Перед началом:

1. VNA/SPDR warm-up минимум `30 min`.
2. Fixture держать горизонтально.
3. Зафиксировать температуру помещения; целевой режим `23 ± 2 °C`; изменение температуры в ходе серии не более `1 °C`.
4. Записать модель VNA, модель SPDR, nominal frequency, software/version.

Измерение:

1. Empty fixture: измерить `f0_empty`, `Q_empty`.
2. S01: вставить → измерить → вынуть. Повторить 3 раза.
3. S02: 3 независимые установки.
4. S03: 3 независимые установки.
5. При аномалии одного образца использовать S04.

Минимум основных измерений: `3 образца × 3 установки = 9`.

Для каждого измерения сохранить:

- sample ID;
- repeat ID;
- temperature;
- actual thickness;
- resonance frequency with sample;
- Q with sample;
- calculated `epsilon_r`;
- calculated `tan_delta`.

## 10. Обработка результата

По 9 измерениям вычислить:

- mean `epsilon_r`;
- sample SD `epsilon_r`;
- CV `epsilon_r`;
- mean `tan_delta`;
- sample SD `tan_delta`;
- CV `tan_delta`;
- отдельно среднее каждого физического образца для оценки sample-to-sample scatter.

Итоговый файл:

`DE10_SPDR_5GHz_RESULT.csv`

Минимальные поля:

```text

epsilon_SD
epsilon_CV_percent
tan_delta_5GHz
tan_delta_SD
tan_delta_CV_percent
decision
```

Raw и processed данные сохранить в `data/materials/de10/`.

## 11. Go / No-Go

Физический предел классической Luneburg:

`epsilon_target(0) = 2`.

Следовательно смесь `DE-10 + air` не может реализовать центр, если measured solid `epsilon_r <= 2.00`.

Решение:

- `epsilon_r <= 2.00` → **NO-GO** для текущей архитектуры resin+air;
- `2.00 < epsilon_r < 2.15` → **технически возможно, но плохой запас**: центр будет почти сплошным;
- `epsilon_r >= 2.15` → **GO** к gyroid calibration;
- желательная зона для текущей архитектуры: примерно `2.25–2.35`.

`tan(delta)` не использовать как произвольный hard threshold. Реальное measured значение передать в M4 loss-sensitivity и принимать решение по влиянию на RCS/focusing.
