# Рупоры, SMA, NanoVNA-F V3 — текущий аппаратный план (09.11.2026)

**Статус: закупка/макетирование и отдельные наблюдения, не завершённая метрологическая верификация.** Этот документ продолжает 5-GHz стенд из experiment/README.md и не меняет канон заказной линзы Ø80 мм / 24 ГГц или физического кандидата Ø120 мм / 5 ГГц.

## 1. Реальный прибор и задача

- Используется **NanoVNA-F V3** с двумя портами, приблизительно до 6.3 ГГц по заявленным возможностям версии; предел, динамический диапазон и достоверность именно имеющегося прибора проверить.
- Доступны два синих коаксиальных кабеля, ранее выполнена калибровка OPEN / SHORT / LOAD / THRU / DONE / SAVE 2. На экране ранее отображались границы **383–483 МГц**: такая калибровка **не годится** для измерений около 5 ГГц. При смене диапазона калибровать заново и сохранить.
- Для 5 ГГц нужны два направленных одинаковых рупора с известным согласованием; запланирован **3D-печатный двойной гребневый рупор ByTechLab** (double-ridged horn, заявленная широкополосность порядка 2–6 ГГц), напечатанные две половины и задняя пластина.
- Корпус печатный, поверхности токопроводящие: медная фольга/лента внутри, включая гребни, и заднюю пластину; полное непрерывное металлизирование важнее декоративного покрытия. Электропроводность клеевого слоя не равна автоматически проводимости самой фольги. Места перекрытия и переходы между половинами требуют проверки.
- В исходной реализации ByTechLab применялись **Amphenol 2950-6061** и электропроводная серебряная краска **MG Chemicals 843AR**, а также металлическая задняя пластина. Это ориентир, не обязательная закупка.

## 2. Ввод энергии через SMA

Планируемый доступный аналог: **SMA-7814-16**, SMA-female, 4-отверстный фланец, удлинённая изоляция PTFE ~16 мм. В объявлении заявлена работа до 6 ГГц; пригодность на 5 ГГц **не доказана** только каталогом. Заказ — упаковка 10 шт., потому что так быстрее; для двух рупоров достаточно двух + запас.

Перед монтажом:
1. Снять реальные размеры разъёма: расстояние между отверстиями фланца, толщина фланца, диаметр корпуса, выступание PTFE, фактическая длина центрального штыря. Не путать длину диэлектрика с длиной свободного контакта.
2. Сверить ByTechLab STEP в Fusion 360. Изменить посадку/опору, если отличается от Amphenol 2950-6061; не давить разъёмом на печатную часть.
3. По задуманной геометрии проверить контакт центрального проводника с **противоположным гребнем** и проводимость внешнего проводника/фланца с другим гребнем. Не замыкать произвольно контакты: токи и геометрия возбуждения задаются конструкцией.
4. Механически закрепить разъём; серебряный проводящий клей — только локальные соединения, не замена правильному креплению и СВЧ-геометрии.
5. Измерить S11 в реальном рабочем диапазоне после новой корректной SOL-калибровки.

**Предварительные наблюдения:** при одной конфигурации контакта штыря сообщалось S11 около −20…−25 дБ, без контакта — около −6…−7 дБ. При приближении металлического листа наблюдалось изменение примерно −18…−3 дБ. Это **не верифицированная серия, не измерение усиления антенны и не доказательство ЭПР**; сохранить как инженерный дневник, не выдавать за итоговые графики. S11 чувствителен к нагрузке, кабелю, калибровке и возбуждению.

## 3. СВЧ-кабели и механический стенд

По закупке: 2 × готовые кабельные сборки **5D-FB 50 Ом 1 м, SMA-male ↔ SMA-male** (Baltic Signal); два SMA-female на рупорах, два SMA-female порта NanoVNA. При таком составе **дополнительные female–female переходники не нужны**. Они лишь увеличивают потери и количество механических интерфейсов.

Кронштейны: возможны PPR-трубы Ø20 мм и 3D-печатные разъёмные зажимы, основания/стойки для двух рупоров; в точке пробы и возле апертуры минимум металла и лишнего пластика. Конструкции, размеры и расстояния пока не зафиксированы.

## 4. План калибровки

1. Зафиксировать частотный интервал, например 4.5–5.5 ГГц (если работоспособность NanoVNA подтверждена), количество точек, формат комплексных S-параметров, портовый режим.
2. Калибровать **OPEN, SHORT, LOAD на обоих портах**, затем THRU; выполнять последовательность по интерфейсу конкретной версии устройства, с одинаковыми плоскостями калибровки — на концах измерительных кабелей. Не применять сохранённый калибровочный диапазон 383–483 МГц.
3. Прикрепить рупоры без перестановки/изгиба кабелей, измерить S11 каждого и S21 пары. Записать настройки, фото и файлы .s2p (если конкретное ПО прибора поддерживает экспорт; иначе сохранить комплексные данные доступным способом).
4. Измерять BACKGROUND / HOLDER / REFERENCE / BASELINE / LENS_NO_REFLECTOR / LENS+REFLECTOR; выдержать одинаковую геометрию и поляризацию, повторять независимо.
5. Отдельно проверить чувствительность к комнатным отражениям, прямой связи TX→RX и расстоянию. Низкое S11 не гарантирует высокую диаграммную направленность.

## 5. Измерение диэлектрика и волноводная идея

Обсуждалось изготовление прямоугольного 3D-печатного волноводного переходника, покрытого проводящим материалом, с держателем плоского образца (~8 мм). Это **концепция оснастки**, не проверенный волновод.

- Пробный S21 между рупорами с образцом сам по себе **не определяет epsilon_r**. Нужны комплексные S11/S21, известная толщина, геометрия, повторяемый пустой/reference замер и подходящая модель инверсии.
- Для волноводного метода обязательно выбрать подходящее сечение и единственную рабочую моду в интересующем диапазоне, проверить экранирование, переходы, отсутствие паразитных мод и калибровочные плоскости. Не считать любую покрытую фольгой трубку поверенным волноводом.
- До поездки к ВНА: закончить рупоры/переходники, подготовить калибровочные принадлежности, чертёж оснастки, список размеров образцов, таблицу состояний и файлы шаблонов.

## 6. Не смешивать приборы

Эти рупоры предназначены для **5-ГГц NanoVNA**. Самостоятельный CW-модуль **CDM324 24.125 ГГц** уже имеет собственные радарные антенны; SMA-разъёмы 5-ГГц рупоров к нему не подключаются.
