# Минимальный честный комплект для защиты — FDM демонстратор

Статус: **план и расчётные оценки, не результаты измерений**. Цель — подготовить защищаемый демонстратор и воспроизводимый протокол, не заявляя неподтверждённый рост ЭПР.

## Не путать две версии
- Заказная версия: **Ø80 мм, 24 ГГц** (по README / D-027).
- Физический исследовательский кандидат: **Ø120 мм, 5 ГГц**. Масштабирование этих версий не является строгим подобием.
- FDM-макет из **двух склеенных полусфер** — отдельная технологическая ветка; не подменяет проверенную фотополимерную градиентную структуру. До выбора диаметра и материала это именно демонстратор.

## Расчётная база (аналитика, без EM-солвера)
При f = 5 ГГц, c = 299792458 м/с: λ = 59.9585 мм.
Для идеальной невозмущённой линзы Люнеберга: ε_r(r)=2−(r/R)²; n(r)=sqrt(ε_r(r)).
- центр: ε_r=2, n≈1.4142;
- r=R/2: ε_r=1.75, n≈1.3229;
- поверхность: ε_r=1, n=1.
Для Ø120 мм: D/λ≈2.0014; объём сплошной сферы = 4π(60 мм)³/3≈904779 мм³≈904.78 см³.
При D=120 мм, λ≈60 мм: ориентир дальней зоны объекта 2D²/λ≈0.48 м. Это не гарантия дальней зоны **антенн** и не достаточное условие корректного RCS-измерения.
Для Ø80 мм при 24 ГГц: λ≈12.49 мм, D/λ≈6.40; это электромагнитно другая постановка.
**Эти формулы не доказывают, что конкретная FDM-структура реализует профиль ε_r.**

## FDM: что реально изготовить
1. CAD: две полусферы с совмещающими метками, посадочными поверхностями, предусмотренным местом для отражателя (если он используется).
2. Печатать образцы (купоны) с теми же стенками, ориентацией и заполнением, что у макета; записать материал, партию, сопло, слой, массу и размеры.
3. Распечатать обе половины; взвесить по отдельности, измерить диаметр и зазор стыка, сфотографировать.
4. Склеить по повторяемой технологии, зафиксировать тип и толщину клеевого шва; после сборки повторно измерить геометрию.
5. Отдельно испытать образец без отражателя и с отражателем. Шов и оболочку считать возможными источниками рассеяния.
6. **Не утверждать градиентную диэлектрическую проницаемость по проценту заполнения**: требуется измерение эффективной ε на купонах или валидированная электродинамическая модель.

## Минимальный эксперимент с доступным NanoVNA
- Две **одинаковые линейно-поляризованные антенны**, гарантированно работающие на выбранной частоте; порты TX/RX, фиксированная геометрия и поляризация.
- Сначала измерить S11 антенн и контрольный S21 между ними; затем по возможности калибровать плоскости кабелей.
- Сохранить **комплексные** Touchstone .s2p на одинаковой частотной сетке для: пустого стенда, держателя, металлического эталона, FDM-макета без отражателя, FDM-макета с отражателем и исходного объекта сравнения.
- Каждое измерение повторить минимум 3 раза с повторной установкой образца; записать расстояния, ориентацию, мощность/настройки и условия помещения.
- Вычитать фон **комплексно**: A = S21_object − S21_background.
- Только при сопоставимой геометрии, корректной калибровке и достаточном отношении сигнал/шум оценивать Δ=20log10(|A_test|/|A_baseline|), K=10^(Δ/10). Если baseline близок к шуму — отношение недостоверно.
- Изменение S21 в тесном помещении само по себе **не является измеренной ЭПР**. Для абсолютной ЭПР нужен эталон с рассчитанной/известной ЭПР и подходящий стенд.
- Если антенн/эталона нет: предъявлять изготовленный макет, CAD, расчёты выше и **протокол запланированного** измерения. Не подменять реальные данные синтетическими.

## Минимальный пакет доказательств
- CAD + скриншоты разреза и структуры; STL каждой полусферы.
- Таблица параметров печати, фотографии, масса и фактические размеры.
- Таблица «расчёт / фактическое измерение / расхождение»; пустые поля до измерения.
- Реальные .s2p, журнал стенда и график только если измерения состоялись.
- Формулировка для защиты: «Изготовлен FDM-демонстратор и подготовлена методика косвенной сравнительной проверки. Подтверждение заданного прироста ЭПР требует отдельного измерения; на данном этапе результат не заявляется».

## Критерий завершения
Демонстратор готов, когда обе половины напечатаны и склеены, задокументированы параметры и геометрия, а расчёт и ограничения измерительной методики воспроизводимы. Цель +10 дБ остаётся **гипотезой** до получения данных.
