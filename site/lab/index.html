ШАГ 04 / ДАННЫЕ

Запишите измерения

Для каждой точки вносите измеренную долю материала и результат при одной частоте, ориентации и геометрии ячейки.

КАЛИБРОВКА

Как получить точку

01Взвесьте образец и измерьте габариты.
02Рассчитайте объёмную долю или получите её у лаборатории.
03Внесите ε из обработанного лабораторного результата и путь к сырым данным.
Серия должна содержать минимум две различные измеренные точки; для рабочего профиля проект рекомендует не менее пяти по печатаемому диапазону. Измерение только |S21| не является значением ε.

ШАГ 05 / ГЕНЕРАЦИЯ

Подготовьте линзу

Генератор строит цельную сферу с гирoидом и локальной подложкой под фольгу. Выберите источник материала.

STL

Параметры

Для обоих режимов требуется ε сплошного PLA из шага 02. Для приближения укажите источник значения. Параметры не гарантируют печатаемость или ЭПР.

ПРОФИЛЬ ЛЮНЕБЕРГА
ε(r) = 2 − (r / R)2

ρ(r) подбирается по измеренным точкам либо по предварительной модели. Ограничения печати обрезают профиль на краях диапазона.

Что проверить перед печатью

CSV-профиль описывает гирoид без сплошной подложки. В STL она присутствует.

ШАГ 06 / СТЕНД

Проверьте линзу

Главное сравнение: линза с отражателем против того же отражателя без линзы, при неизменной геометрии.

ИЗМЕРЕНИЕ

Последовательность

Фон вычитается из комплексного S21, а не из значений в dB. +10 дБ — цель проекта, не результат по умолчанию.

ШАГ 07 / ОБРАБОТКА

Сравните отклики

Расчёт для одной частотной точки и одной установки. Значения — комплексные S21 в линейных единицах, не в dB.

РАСЧЁТ

Комплексные значения S21

Заполните все шесть чисел из одной частотной точки.

Условия сравнения

Δ = 20 log₁₀(|Sлинза − Sфон| / |Sбаза − Sфон|). Это относительное сравнение, не абсолютная ЭПР. Если база близка к шуму, отношение ненадёжно.
ШАГ 08 / ИТОГ

Соберите результат

Отделите напечатанные и измеренные результаты от предварительных расчётов.

ОТЧЁТ

Перед выводами

Целевая линза проекта Ø80 мм на 24 ГГц требует отдельного расчёта. Измерения на 5 ГГц не являются измерением материала на 24 ГГц.
