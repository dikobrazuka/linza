# Система данных для GitHub Pages

Канонические редактируемые JSON:
- `project.json`: 3 образца, параметры и первичные источники;
- `procurement.json`: 32 строки корзины / 24267 ₽, DE-10 вне суммы, прочие TBD;
- `actions.json`: 24 действия по пайке, стенду и трём линзам, с документами.

Сайт должен читать эти файлы по относительному пути `./data/`. Они не означают состоявшуюся покупку или опыт. Не заменять факты вымышленными числами/измерениями.

См. `../../AGENTS.md` и `../../docs/SITE_SOURCE_OF_TRUTH.md`. GitHub Pages статичен; изменения в браузерном localStorage не записываются в эти JSON или GitHub. Для синхронизации нужна отдельная серверная/аутентифицированная реализация.
