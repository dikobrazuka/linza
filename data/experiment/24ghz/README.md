# CDM324 24.125 GHz — записи (пока пусто)

**Нет реальных измерений на 09.11.2026.** Для лётного опыта используйте docs/21_CDM324_24GHZ_ELECTRONICS.md и docs/22_DJI_FPV_24GHZ_FLIGHT_DEMO.md.

Структура будущего опыта:
- raw/ — исходные массивы отсчётов АЦП (CSV или бинарный поток + метаданные реальной частоты дискретизации);
- runs.csv — метаданные тестов: ID, bare/holder/lens, тип дрона, масса, маршрут, расстояние, скорость, курс, настройки усилителя, дата, оператор, фото;
- processed/ — FFT, шум, амплитуда, доверительные интервалы, результаты по сопоставимым сериям;
- README с точной версией схемы, платы и прошивки.

Запрещено заполнять примерами как будто они являются реальными опытами. Прежде чем записывать dB gain, проверить фон, насыщение, стабильность расстояния и усиление. Полученный результат — изменение Doppler IF response, а не абсолютная ЭПР.
